# 代码拆分清单（单文件硬上限 800 行）

依据：根 `AGENTS.md`「硬性约束」那条「单文件别长成上帝类」（2026-10-04 用户拍板，门限 **800 行**）。
「一个脚本只担一类职责」是目标；800 行是**能自动盯住的门限**，两者不冲突。

量法（行数变化后重跑这条刷新本表）：

```powershell
Get-ChildItem src,tests,tools -Recurse -Include *.gd,*.cs |
  ForEach-Object { [pscustomobject]@{ Lines = (Get-Content -LiteralPath $_.FullName).Count;
                                       Path  = $_.FullName.Substring((Get-Location).Path.Length+1) } } |
  Where-Object { $_.Lines -gt 800 } | Sort-Object Lines -Descending
```
