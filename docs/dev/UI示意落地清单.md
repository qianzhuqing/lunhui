## 一、全局：入口、跳转、关闭（12 屏共用）

```
        底栏七入口（常驻，互为跳转；当前所在高亮）
   地图   行囊   武学   角色   纪事   系统   装备
    │      │      │      │      │      │      │
  回场景  行囊屏 武学页 属性页 线索本  系统屏 装备页
                 └────── 角色面板内部三页签互跳 ──────┘
```

| 规则 | 内容 | 依据 |
|---|---|---|
| 打开浮层 | **压栈**（`OverlayStack.push`） | 14 §一 |
| 目标已在栈里 | **弹回它**，不重复压（A→B→A 回到 A） | 14 §一 |
| `Esc` | **弹一层**；栈空回场景。所有浮层关闭提示**统一写 `Esc`**，不出现「关闭全部」 | 14 §一／§四 |
| 栈深 | 上限 **3**，再压挤掉栈底 | 14 §一 |
| 压栈后 | **必须重读状态**（调该浮层的 `refresh()`），不许复用旧快照 | 14 §一 |
| 全局快捷键 | **在任何浮层里都生效**：`Tab` 角色／`I` 行囊／`K` 线索本／`M` 副本完成度 | 14 §八 |
| 底栏七入口 | 常驻功能栏，等价于快捷键的鼠标路；**入口是「浮层＋页签」的二元组**（例：装备＝角色面板的装备页） | 示意图（用户认可）；14 §六 已登记 |
| 位置 | 底栏贴屏幕底部；`Esc` 提示与键位提示在**底部说明行**，不占标题栏 | 14 §三 |

## 四、落完怎么验

1. **版式**：每个浮层照现在的规矩量两层——外壳走 `LAYOUT`、滚动区内容走 `CONTENT`（逐页切＋等一帧），上限 1152×648 两个方向都过。
2. **门限**：界面文字不许出现表内 id（`CopyGuard`／`_check_no_id_tokens` 已盯）；底栏与页签的**当前项高亮**要有断言。
3. **真窗口**：改完界面／贴图后跑一次 `tools\run_windowed_smoke.bat`（headless 抓不到贴图与字体）。
4. **栈**：新加的浮层都要走 `OverlayStack`（`mount()` 收口的事不用再记），并补「已在栈里就弹回」与「栈深 3 挤栈底」两条用例。
5. **顺序建议**：先做**只读**（角色详情排版、武学切人、纪事五类）→ 再做**写操作**（装备换装对比、系统开关）→ 最后做**新弹窗**（道具使用、悬停小卡）。理由：只读的那些不碰存档，改错了也不会污染档。
