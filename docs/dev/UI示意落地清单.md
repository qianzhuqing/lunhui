## 四、落完怎么验

1. **版式**：每个浮层照现在的规矩量两层——外壳走 `LAYOUT`、滚动区内容走 `CONTENT`（逐页切＋等一帧），上限 1152×648 两个方向都过。
2. **门限**：界面文字不许出现表内 id（`CopyGuard`／`_check_no_id_tokens` 已盯）；底栏与页签的**当前项高亮**要有断言。
3. **真窗口**：改完界面／贴图后跑一次 `tools\run_windowed_smoke.bat`（headless 抓不到贴图与字体）。
4. **栈**：新加的浮层都要走 `OverlayStack`（`mount()` 收口的事不用再记），并补「已在栈里就弹回」与「栈深 3 挤栈底」两条用例。
5. **顺序建议**：先做**只读**（角色详情排版、武学切人、纪事五类）→ 再做**写操作**（装备换装对比、系统开关）→ 最后做**新弹窗**（道具使用、悬停小卡）。理由：只读的那些不碰存档，改错了也不会污染档。
