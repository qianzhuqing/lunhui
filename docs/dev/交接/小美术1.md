5. **护手别做太厚**（12×3 那版护手快赶上刃长，整把读成锤子）。现在 15×**2**——
   跨度大、厚度薄。
6. **柄头画成横杠 → 和护手撞脸，读成"双十字"**。现在是一块 4×2 的实心方。

另外两处一起定了：

- **`paint()` 去掉棋盘抖动**。原来"上左 2px 与下右 2px 只有一个够得着就抖"，在 5px 宽的刃上
  等于**整个刃都在抖**，形体被抖成一团毛（四种上色并排比过：平色／亮暗边／三阶无抖／抖动，
  抖动那版最难认）。**"没有剑的形状"有一半的原因在颜色、不在构图。** 现在按"离边缘几步"
  分五档、每档都是实心块；参考图那把剑本身也是一整块平色，抖动只落在大色块的边缘。
- **姿态角收进 35°–105°**。近水平的剑（原来的分水 25°、落雁 −8°）在 32px 上会被读成
  "飞机/翅膀"（护手成了机翼）。分水改 38°、落雁改 105°（左倾下劈＋左下雁群），
  既保住"靠姿态区分"，又不掉出可读区间。
- **"势"那几笔不许出格**：`buildOne()` 现在把剪影与描边一起**裁在格子内圈之内**（合 A2 那圈
  米色细边是卡片的边框）。第一版起手式那道开手弧正好压在左下角、音波三道弧出事在左边缘，
  出格之后被裁成一根**竖杠**，看着像脏点——这类"势"一律先算好中心与半径再落笔，
  并且**同时满足下面那轮加的间距门限**。

#### 2026-10-11 深夜·第六轮：用户"靠近剑尖那里变形了，你再优化一下"

**症状**：剑尖收成一截**偏在一边的竖墙**（`x=22` 竖着 4 格，行宽 4、5、6、7 一路加宽），
读起来像"剑尖被削掉一块"。看剪影的 ASCII 就能直接看到，不用猜（`_map.js` 打出来一眼的事）。

**两个根因，都在"收尖按什么量"上**：

1. **收尖不能用像素自己的 `u`。** 45° 上同一行的像素 `u`（沿轴）和 `v`（离轴）是**一起涨**的
   （`x` 每 +1，两个各 +0.707），拿 `u` 去收，收掉的永远是"离轴更远的那一侧"——
   左边缘老老实实按 45° 退，右边缘原地不动 → 竖墙。
   改成按 **`uRow`（本行与轴的交点）** 收：同一行所有像素 `uRow` 相同，于是每一行
   **整体**变窄、且始终关于轴对称。90° 摆时 `cot = 0`，两种算法本来就相等，
   所以这一条只影响斜着摆的剑。
2. **收尖长度必须 ≳ 半宽，否则收不出一格宽的点。** 45° 上一行只前进 0.707，而行宽每降一档
   需要半宽掉 0.707 —— 给 3 只够降两档（7→5→3），最后一行剩 **3px 平头**；
   给 **4.7** 正好降到 1、3、5、7 四级，尖才是一个点。
   **代价**：4.7 是刃长 18 的 26%，比用户那句"80% 以上的剑身是直的"多了一点——
   这一条**只让在"点 vs 短尖"上，选了点**（写在 `SWORD.tip` 的注释里了）。

**顺带换掉了画法**：`sword()` 从"沿轴走、每处按法线落 N 个像素"（`bar()` 那一套）改成
**逐像素判定**——把像素中心投影到 `(u, v)`，落在半宽曲线里就点亮。带来的好处：
① 宽度只留"垂直像素"一个口径，45°／90° 画出来一样粗（原来那个 `1/max(|nx|,|ny|)`
   硬补正连同它的副作用一起删掉了——补正会把 45° 的护手顶到出格）；
② 不再 `round` 像素位置，**镜像格子的 `|v|` 必然相等 → 剑尖、护手两端、刃缘天然左右对齐**。
   ⚠️ 这要求**起手点是整数**（45° 的轴 `x+y = x0+y0−1`、90° 的轴 `x = x0−0.5` 都把格心映到格心）。

实测（`_map.js` 打出来的剪影）：尖端是 `1、3、5、7` 四行、每行中心都落在轴上；
剑全长仍是 26、柄头仍在 `(5,22)`（**位置/方向/大小一个字没动**，只修了尖）。
九张的"势"间距反而松了 1px（**4–6px**，门限 ≥3）。
产物：`tile_v18.png`（对比图）、`tile_strip.png`（九张 12× ）、`tip_zoom.png`（剑尖 20× 放大：
左＝剪影、右＝成品）。

**怎么判空位**（下一轮要换构图时照这个来，别再凭眼睛试）：`_map.js` 那种三行活儿——
`new Canvas(32,32)` ＋ `sword(m, 5, 22, 45, 26, [255,255,255,255])`，再把 alpha 打成 32×32 的
ASCII，就知道刃缘压在哪条线上。⚠️ `sword()` 的 color 参数**要数组不要 `INK`**（`INK` 是
`"#0E1113"` 字符串，传进去会静默画不出东西）。
