# 设计 → 代码 对照清单

**这份表回答的是「设计文档里写了什么、代码里做到哪」。** 与 `模块对接表.csv` 互补：
那张表是「模块 → 设计／表 → 状态」，正着查；这张是**反着查**——从设计文档逐条核对实现，
用来找「设计写了但代码里没有」的漏项。

维护规则：策划改需求后，除了跑 `tools\run_tests.bat` 的那个强制流程，也顺手核对本表相关行。
状态只有四种：

| 状态 | 含义 |
|---|---|
| ✅ 已完成 | 代码里有实现，且有断言钉着 |
| 🟡 部分 | 主链路能用，但有明确缺口（缺口写在「证据」列） |
| ⛔ 未实现·等设计 | 缺表／缺列／原文只有一句话没有规则，开发侧不该自己编 |
| ⛔ 未实现·等地编 | 缺位点／贴图，开发侧不动地图资产 |
