# 17 参考资料（GitHub 调研）

> 调研时间 2026-10-04，数据来自 GitHub 公开搜索 API。
> 星数与授权会变，**采用前请再核一次**。

## 一、中文字体：本项目最大的隐藏风险

**像素游戏做中文，字体是第一个会卡住的地方。**

市面上绝大多数像素字体只覆盖拉丁字母，中文字形有几万个，
能覆盖简繁的像素字体屈指可数。如果按美术文档选了像素风却找不到配套的
中文像素字体，整套界面就得退化成系统字体——**像素风立刻不成立**。

### 候选对比

| 仓库 | 星 | 授权 | 可用性 |
|---|---|---|---|
| `TakWolf/ark-pixel-font` | 4766 | **OFL-1.1** | ✅ **推荐** |
| `TakWolf/fusion-pixel-font` | 3270 | **OFL-1.1** | ✅ 备选（同一作者，风格不同） |
| `SolidZORO/zpix-pixel-font` | 3051 | **无声明** | ⚠️ 不敢用 |
| `wixette/dotted-chinese-fonts` | 439 | GPL-2.0 | ⚠️ 传染性，慎用 |

**结论：用 `ark-pixel-font`。**

理由三条：

1. **OFL-1.1 授权**，商用无风险（随包带 `OFL.txt` 即可；**别写成 MIT**，那是仓库代码的授权）
2. 覆盖**泛拉丁 ＋ 泛中日韩**，简繁都有
3. 4.7k 星，是这类字体里最活跃的

### 两个要避开的坑

**没有授权声明的字体不能用。** `zpix` 有 3k 星、质量也好，
但仓库里没有 LICENSE，**这不等于免费**——商用项目用它等于把风险留到发行时。

**GPL 字体对闭源游戏有传染性。** 字体文件若被认为构成"衍生作品"，
会牵出整个游戏的授权问题。除非愿意把游戏也开源，否则不要用。

### 落地要求

| 项目 | 要求 |
|---|---|
| 字号 | **必须是设计像素尺寸的整数倍**——本项目只用 **12px 那一份字集**：正文 24px（×2）、标题 36px（×3） |
| 缩放 | 禁止非整数缩放，与像素图同一口径 |
| 回退 | 配一份系统字体作回退，避免缺字时显示方框 |
| 授权 | `assets/fonts/` 下**必须带 LICENSE 原文**（本项目是 `OFL.txt`） |

> **A11（2026-10-04 定）**：上游 `ark-pixel-font` **2026.09.01 之后废弃了 16px 尺寸**——
> 最后那版里 16px 的简体只有 68KB（12px 是 738KB），是空壳不是字集。
> 所以**不要再规划 16px 档**：标题改走 12px ×3＝36px（见 15 §4.4）。

最后一条是纪律：字体是最容易"随手下载就用"的资源，
而它恰恰是发行时最容易被追责的一类。

## 二、同类项目参考

### 武侠题材的 Godot 项目

| 仓库 | 星 | 能学什么 |
|---|---|---|
| `ttwings/WuXiaAndJiangHu_Godot` | 52 | 武侠题材的 Godot 结构组织 |
| `AmethystineAlpaca/moonlit-jianghu` | 10 | Godot 4.6 做武侠；**含 2D 与 3D 两版**，可以看它 2D 版的取舍 |

这两个规模都小，**不要照抄代码**，但可以看两件事：
他们怎么切分"地图／战斗／对话"，以及武侠题材的资源组织方式。

### 回合制战斗

| 仓库 | 星 | 能学什么 |
|---|---|---|
| `gdquest-demos/godot-open-rpg` | **2995** | Godot 官方合作方的开源回合制 RPG 示范 |
| `mikasasukasa/Godot-TBS-RPG` | 123 | 回合制策略 RPG 的项目结构 |

`godot-open-rpg` 是这批里最值得看的：**它是教学性质的开源项目**，
结构清楚、注释完整。虽然我们的战斗是"即时指令回合制"而不是战棋，
但它在**回合推进、行动队列、界面与逻辑分离**上的做法可以直接借鉴。

**重点看它怎么把"战斗状态"与"界面"分开**——这正是我们
`battle_simulator` 与 `battle_screen` 的切分方式，可以对照检查有没有漏。

## 三、素材来源

### 现状

项目当前用的是 **Kenney Tiny Town（CC0）**，见
`assets/tilesets/kenney_tiny_town/`。CC0 意味着可商用、可改、无需署名，
是**占位资源最稳妥的选择**。

### 搜索结论：没有现成的"像素武侠"素材集

GitHub 上按 `wuxia sprite`、`pixel tileset 16x16`、`guofeng` 等关键词搜，
命中的大多是零星的个人项目，**没有一个成规模、授权清晰的中国风像素素材集**。

这说明一件事：**美术资源要自己出，不要指望找到现成的。**

### 可以复用的部分

| 类型 | 来源 | 说明 |
|---|---|---|
| 中文字体 | `ark-pixel-font` | OFL-1.1（随包带 `OFL.txt`），可直接用 |
| 通用像素素材 | Kenney 系列（CC0） | 补零散物件（图标、UI 件）时可以找 |
| 中国风素材 | **无可靠来源** | 必须自制 |

**所以第 15、16 号文档里的美术需求是"必须自己做"的清单**，
不是"去买或下载"的清单。这一点在排期时要算进去。

## 四、三条结论

**一、字体先落地，再谈美术风格。** 中文像素字体是像素武侠的前置条件，
它不到位，界面风格无从谈起。用 `ark-pixel-font`（OFL-1.1）。

**二、不要下载无授权声明的素材。** 三星以上的素材仓库也有不带 LICENSE 的，
**星数不是授权**。

**三、资源自制的比例很高。** 中国风像素素材没有成熟来源，
排期按"自制"算，别按"找现成的"算。

## 五、怎么复核

本文的结论可以重跑。搜索用的关键词与接口：

```
https://api.github.com/search/repositories?q=<关键词>&sort=stars
```

用过的关键词：`wuxia+godot`、`chinese+pixel+font`、`turn+based+rpg+godot`、
`pixel+tileset+rpg+assets`、`jianghu+game`。

**采用任何资源之前，去仓库根目录确认 LICENSE 文件存在且授权允许商用。**
