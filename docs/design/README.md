# 《轮回》策划文档索引

本目录存放游戏策划文档。数值配置文件在 `data/tables/`，字段含义见 [06_配置表说明](06_配置表说明.md)。

> **改动文档或配置表时，两边必须同步更新。** 完整规则见项目根目录的 `AGENTS.md`。
> 改完跑一次校验：
> ```powershell
> powershell -ExecutionPolicy Bypass -File tools\validate_tables.ps1
> ```
