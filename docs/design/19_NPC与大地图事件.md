# 19 NPC 与大地图事件

## 一、城镇要够大、够显眼

**问题**：大地图上的城镇太小，玩家认不出那是城镇。

| 对象 | 占地 | 图标 |
|---|---|---|
| **城镇** | **3 × 3 瓦片（48×48）**，硬下限 2×2 | **48×48**，地形轮廓 + 建筑剪影 |
| 副本 | 2 × 2（32×32） | 32×32，寨门／塔楼剪影 |
| 驿站 | 2 × 2 | 32×32，旗杆剪影 |
| 兴趣点 | 无固定占地 | **不给图标**（见 16 号：探索乐趣来自自己发现）；**未揭开时地图上连地名都没有**，揭开后只显示地名 |

**城镇不是一个贴上去的图标，而是一片拼出来的地形**——
屋舍、院墙、道路一起构成轮廓。图标只是叠在上面的强调。

理由是这张图的功能：玩家在大地图上找的是"能落脚的地方"，
一个小图标和大片建筑轮廓，读懂的成本完全不同。

## 二、NPC 系统

本章的 NPC 从「按 E 触发固定结果」升级成**可以交往的人**。

### 2.1 四张表

| 表 | 管什么 |
|---|---|
| `npc_def` | 身份、位置、称号、**基本信息**、切磋队伍 |
| `npc_favor` | 好感度规则：初始值、上限、喜好、赠送与切磋收益、偷窃难度 |
| `npc_offer` | **可兑换与可偷的道具**（含好感门槛与价格） |
| `npc_quest` | **NPC 专属任务线** |

### 2.2 好感度

| 行为 | 效果 | 配置 |
|---|---|---|
| **赠送** | 加好感；送对喜好加得多 | `gift_favor` ＋ `like_item_ids` / `like_categories` |
| **切磋** | 赢了加好感 | `spar_favor` |
| **完成任务** | 加好感 | `npc_quest.reward_favor` |
| **偷窃失败** | 扣好感 | 由偷窃系统处理 |

**喜好分两级**：

- `like_item_ids`：具体物品（最爱），送一件加很多
- `like_categories`：类别（如 `material`），送同类加一点

分两级是为了让"投其所好"有层次：**送对具体物品是惊喜，送对类别只是礼貌**。

### 2.2 补：好感度的四个数（0.28.0 定）

表里只有 `gift_favor`（一次赠送的基础值）与 `spar_favor`（切磋赢的基础值），
「送对／送错／偷窃失败」这三档原先只在散文中，现定死：

| 行为 | 变化 | 为什么是这个数 |
|---|---|---|
| **送中最爱**（`like_item_ids`） | `gift_favor` ＋ **8** | "投其所好"要有明显回报；钱大夫那种 5＋8＝13 |
| **送对类别**（`like_categories`） | `gift_favor` ＋ **2** | 只是礼貌，与"最爱"拉开四倍 |
| **送错东西** | **−3** | 送错是失礼，不该比偷窃失败更伤 |
| **偷窃失败（被发现）** | **−8** | 偷是**敌意行为**，代价必须明显高于失礼 |
| 切磋赢 | `spar_favor`（表里 4～8） | 表驱动 |
| 切磋输 | **0** | 输了不罚——不然玩家不敢切磋，"切磋"这个交互就废了 |
| 完成任务 | `npc_quest.reward_favor`（表里 10～30） | 表驱动 |

**关键的一条是「送错 3 分、偷窃失败 8 分」这个比例。** 两条都是负分，但
如果一样重（开发侧先给的默认是两边都 −5），那么"偷一下试试、失手也只是回到原点"
就成了最优解——**偷窃的紧张感来自失手真的疼**。

### 2.3 偷窃

`npc_offer.kind=steal` 的道具可以偷，难度在 `npc_favor.steal_difficulty`。

**三条规则**：

1. 偷窃走**事件判定**（敏或运），不是战斗
2. **失败扣好感**，且**当场被发现会有后果**（后续按好感度调整态度）
3. **不是所有 NPC 都能偷**——`steal_difficulty=0` 表示不可偷

判定口径（0.28.0 定）：**判定值取「敏」与「运」里高的那个（裸值，不含装备）**，
对表里的 `steal_difficulty`；走**既有 soft 口径**（达标必过、不足按
`0.5 ＋ 差值 × 0.1` 掷、夹 5%～95%）——**不新造一套公式**，
与 `event_check` 的 soft 判定是同一条（见 01）。

所以「偷不偷得着」是**角色养成**的结果：运高的角色偷窃更容易，
这也让「运」在战斗之外有一处正经用途。失败只扣好感（见「已定口径」第 1 条），
不引入通缉或商店涨价。

第 3 条是为剧情留的口子：有些 NPC 是纯善意的（比如救出来的阿福），
不该让玩家去偷他。

### 2.4 好感度兑换

`npc_offer.kind=offer`，需要 `favor_required` 与 `price`（可为空＝只靠好感）。

**这是「特有道具」的出口**：三件 NPC 独有装备都走这条路，
`drop_only=1` 保证它们不会从别处冒出来。

| 装备 | 归属 | 拿法 |
|---|---|---|
| 铁匠印记 | 王铁 | 好感 60 ＋ 400 文 |
| 药王符 | 钱大夫 | 完成他的委托（好感 80） |
| 猎户披肩 | 老周 | 治好他的腿（医术判定 2） |

**三件都走非武器槽**（戒指／项链／肩部）——武器槽受武器类型限制，
NPC 给一把"不该存在的枪"会破坏 05 定的四种武器。

### 2.5 NPC 专属任务线

`npc_quest` 按 `sort_order` 串成一条线，每条有 `requirement`（达成条件）
与 `reward_item_ids` / `reward_favor`。

**条件复用既有系统**，不新造一套：

| 条件写法 | 含义 |
|---|---|
| `item:item_iron:10` | 持有 10 个铁矿石 |
| `flag_xxx` | 某个旗标已置 |
| `event:ev_herbalist_help` | 某条事件判定已成功 |
| `kill_style:poison` | 用某种击杀方式击杀过 |

这样 NPC 任务和主线、隐藏内容用的是**同一套条件语言**，
以后加 NPC 不用改代码。

## 三、NPC 基本信息面板

**所有 NPC 都能查看基本信息**（第 4 条要求）。

```
┌─ 王铁 ────────────────────────┐
│ 清风驿铁匠            好感 35 │
│ 好感度 ████░░░░░░            │
│                              │
│ 清风驿的老铁匠，打了三十年铁。│
│ 据说年轻时在镖局走过镖，      │
│ 手上有一道刀疤。              │
│                              │
│ Esc 返回                     │
└──────────────────────────────┘
```

三个要点：

| 要点 | 理由 |
|---|---|
| **必须显示好感度与条形** | 玩家要判断"还差多少能换东西" |
| 信息来自 `npc_def.info_text_cn` | 文案在表里，不写死在代码 |
| **文案要有一句"人味"**（刀疤、脾气、旧识） | 纯功能说明会让 NPC 变成自动售货机 |

**信息面板与交互菜单分开**：按一个键看信息，按另一个键进入交互（赠送／切磋／偷窃／兑换／任务）。
合在一起会让"我只是想看看这人是谁"变成一次有风险的操作。

**键位（0.28.0 定）：**

| 键 | 动作 | 说明 |
|---|---|---|
| **E** | 进入交互菜单 | **沿用既有的 `interact`**——建筑、位点、NPC 都是 E，不改玩家的肌肉记忆 |
| **Q** | 查看信息面板 | 新增一个 action（`npc_info`），只在城镇 / 有 NPC 的地方生效 |

**为什么不让 E 一个键做两件事**：`E` 已经绑着"进店、触发位点、读判定"，
它是一个**会改变世界状态**的键。把"看一眼这人是谁"塞进去，
等于每次好奇都要经过一次有后果的交互——这正是设计要避免的。

信息面板本身是**只读**的：打开、看、`Esc` 关，不带任何副作用。

## 四、大地图随机事件

**问题**：明雷默认关之后，大地图除了地形什么都没有，走起来很空。

**解法**：按区域权重随机触发**非战斗事件**。配置见 `world_event.csv`。

| kind | 含义 | 例子 |
|---|---|---|
| `caravan` | 货商流通 | 商队歇脚，可以买卖（有限量品） |
| `disciple` | 门派弟子历练 | 别派弟子，可以切磋 |
| `wanderer` | 江湖人 | 问路、搭话、给钱 |
| `official` | 官府 | 镇抚司巡查，过判定否则打点 |
| `omen` | 天象异物 | 隐士、路遗、怪事 |
| `beast` | 野物 | 野狗拦路 |

### 每条事件的效果指向（`effect_id` 已配齐，0.28.0）

`effect_kind` 决定 `effect_id` 指向哪张表——**开发侧不替设计编效果**，
所以这一列原先八行全空，现在填齐：

| effect_kind | `effect_id` 指向 |
|---|---|
| `trade` | `shop_stock.shop_id`（货架组） |
| `spar` | `enemy_team.team_id` |
| `hint` | `hidden_trigger.trigger_id`（补一条线索） |
| `gift` | `item_base` / `equip_base` 的物品 id |
| `check` | `event_check.check_id` |

| event_id | 事件 | effect_kind | effect_id | 玩家实际拿到什么 |
|---|---|---|---|---|
| `we_caravan` | 货商车队 | `trade` | `shop_caravan` | **新增货架**：药酒／金创药／回气散／玉戒，都比城镇贵且限量 |
| `we_disciple` | 门派弟子历练 | `spar` | `team_wanderer_disciple` | 别派弟子 ×2 可切磋（**新敌人** `en_wanderer_disciple`） |
| `we_wanderer` | 江湖人问路 | `hint` | `trig_stealth_clear` | 给「潜行入寨」添一条线索（寨子的换防规律） |
| `we_hermit` | 隐士奇遇 | `gift` | `eq_sword_04` | 良品剑**「锈月」**——它原先没有任何来源，这里补上 |
| `we_lost_item` | 路遗 | `gift` | `item_herb` | 草药（同时也是钱大夫／老周的最爱材料） |
| `we_patrol` | 镇抚司巡查 | `check` | `ev_patrol_check` | **新判定**：文学 4、soft；过不去要打点（官道上另有一个固定关卡位点，共用这行） |
| `we_rumor` | 驿站风声 | `hint` | `trig_wine` | 给隐藏 Boss「醉刀客」添一条线索 |
| `we_dog` | 野狗拦路 | `gift` | `item_pelt` | 兽皮 |

三条说明：

1. **`hint` 指向的是 `hidden_trigger`，不是散文**——玩家在别处听到一句话，
   那条隐藏内容的 `clue_source` 就真的多一条。**03 的「每条隐藏至少两条线索」
   可以靠随机事件补齐**，这正是当初把 hint 设成一类效果的原因。
2. **`gift` 顺手补了两个洞**：锈月（原先无来源）与草药（两个 NPC 的最爱）。
3. **`ev_patrol_check` 有两个入口，判定行只有一条**：官道上的**固定关卡**
   （`Event_ev_patrol_check`，按 E 触发）与**随机事件** `we_patrol`。
   事件那条走「**直接结算**」——不要求玩家走到关卡，所以 `world_event` 的
   resolve 路径要能直接调判定，而不是走 `_collect_events` 的位点收口
   （表里填了 `region_id=n_post_station`，过得了 `check_allowed_in_scene`）。

### 三条设计纪律

**一、事件以「非战斗」为主。** 明雷关掉正是因为大地图不该有战斗，
**如果随机事件又变成打架，等于把明雷偷偷加回来**。战斗类只保留"切磋"，
而且是玩家主动选的。

**二、权重按区域给。** 商队走官道、弟子在野外历练、野狗在荒处——
**每个区域的随机池不同，才能让"这是哪"有实感**，而不是全图一个池子。

**三、事件要给"东西"或"信息"。** 只是看一眼就走的随机事件等于空气。
要么给道具、要么给线索（`we_rumor` 是主线线索的重要来源）、
要么给一次判定机会。

### 与明雷开关的关系

`feature_toggle.overworld_roaming_enemy` 打开时（明雷回来），
随机事件照常触发——**两者不互斥**，一个是被动遭遇，一个是主动交互。

### 随机事件必须有提示

**不能"走到范围内直接触发"**——那样玩家只会觉得地图在随机弹东西，
既不知道有事、也不知道错过没。

提示分两处，**一明一暗**：

| 位置 | 内容 | 来源 |
|---|---|---|
| **HUD 一行** | 模糊的方向性提示：「远处有车马声」「洞口外好像坐着人」 | `world_event.prompt_text_cn` |
| **地图上一个临时标记** | 比地标小、比兴趣点显眼的淡色光点，会随事件消失 | 事件存活期间 |

**提示要模糊，标记要能看见。** HUD 不说"商队"只说"车马声"，
保留探索感；但只要玩家想找，地图上一定找得到——**"错过了"必须是玩家的选择，不是系统的疏忽**。

三条规则：

1. **提示只在事件存活期间出现**，事件消失提示也消失
2. **同一时刻最多一条 HUD 提示**，多个事件按距离取最近的那个
3. **玩家走开或超时，标记消失**——随机事件是"路过遇上"，不是"待领的任务"

### 随机事件与「兴趣点不给图标」不矛盾

16 号文档定了「兴趣点不给图标」，那是**固定地点**——藏着的，发现本身是奖励。

随机事件是**临时出现**的，性质不同：**不给提示就等于随机丢失内容**。

| | 兴趣点 | 随机事件 |
|---|---|---|
| 存在 | 永久 | 临时 |
| 图标 | **不给**（探索乐趣） | **给提示**（临时标记） |
| 理由 | 发现本身是奖励 | 错过了玩家也不知道 |

## 五、藏宝图任务线：石隙迷窟

一条**完整的隐藏支线**，从偷窃开始，到第一章最高品质的内功结束。

```
偷张贵的藏宝图（唯一入口）
   ↓ 大地图揭示「石隙迷窟」
落雁坡西边·石隙入口
   ↓ 小迷宫（6 间，两处死路）
10 级石隙巨狼 ×2
   ↓
遗篇石台 → 遗篇残卷 → 研读学会《遗篇·归元》（★5 内功）
```

### 5.1 唯一入口是偷窃

`npc_offer.of_zhang_treasure` 的 `kind=steal`，**没有 `offer` 版本**——
不能买、不能打、不能任务换。

这是「偷窃」这条机制**第一次成为主线级入口**：
在此之前它只是拿点零碎道具的旁门；现在**不偷就永远见不到这条线**。

张贵这个 NPC 也选得合适——他是"消息灵通"的酒楼掌柜，
**手里有张自己也说不清来历的图**，很符合人设。

### 5.2 迷宫要真的会迷

小地图 `scene_shixi` 共 6 间，**两处死路**：

| 房间 | 类型 | 出口 |
|---|---|---|
| 石隙入口 | 入口 | 石廊 ／ 塌方 |
| 石廊 | 战斗（巨狼） | 岔口 |
| **塌方** | 宝箱（**死路**） | **回入口** |
| 岔口 | 战斗（巨狼） | 空室 ／ 遗篇石台 |
| **空室** | **死路** | 回岔口 |
| 遗篇石台 | 终点 | — |

**塌方那间是要点**：它有个宝箱，但走进去只能回入口——
玩家会拿走箱子，然后发现自己白走一趟。**这是"迷"的核心体验**，
不是靠把路画复杂，而是靠**给出诱饵再让你回头**。

### 5.3 难度定位：10 级

小迷宫的野怪是 **10 级**，比第一章主线（3–8 级）高一档。

理由：这条线**只有偷过东西的人才会遇到**，所以进来的人至少已经玩了一阵。
定 10 级是**给已经练过的人准备的挑战**，不是给新手的。

同时它也是"练级有回报"的正面反馈——**木桩只能练到 5 级，剩下的差距靠这里补**。

### 5.4 奖励：第三部 ★5 内功

第一章原本有两部 ★5 内功：

| 内功 | 来源 |
|---|---|
| 玄微心法·太清 | 章节末回城复命 |
| 醉里乾坤·忘忧 | 隐藏 Boss 醉刀客 |

**新增第三部 `遗篇·归元`，不抢前两个的来源。** 理由是这条线最深：
要偷东西、要找地点、要过迷宫、要打 10 级怪——**它该有自己的独特回报**。

三部 ★5 也正好对应三条不同的深挖路线：

| 路线 | 拿到什么 |
|---|---|
| 走完主线 | 太清 |
| 打赢隐藏 Boss | 忘忧 |
| 偷东西 + 探迷宫 | 归元 |

### 5.5 奖励走既有通道，不扩枚举

终点给的不是"直接学会内功"，而是**遗篇残卷**（`item_scroll_yipian`），
研读后才学会。

这样走的是 `skill_grant` 已有的 `item` 通道，**不用给 `hidden_trigger.reward_type`
加新枚举**。而且"得到一部秘籍"比"凭空学会"更有仪式感。

### 5.6 藏宝图怎么揭示地点

`map_region.n_shixi` 的 `unlock_condition = item_treasure_map`——
**持有藏宝图之前，这个地点在大地图上根本不存在**。

这也让 16 号定的"兴趣点不给图标"有了例外：藏宝图指向的地点**给了图标**。
理由是它已经不是"兴趣点"了——**玩家手里有图，图上有位置**，
再藏起来就是跟玩家作对。

**0.32.0 补**：这个例外连图标的值一起定了——`n_shixi.icon = icon_shixi`
（美术交付的 `assets/sprites/icons/icon_shixi.png`：劈开的窄岩缝＋一线天光，
与塌陷山洞的圆洞口刻意相反）。其余三个兴趣点的 `icon` 留空，揭开后只有地名。

## 六、这条线补齐了什么
