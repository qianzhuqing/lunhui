# 16 区域美术设定

> 风格总纲见 [15_美术风格需求](15_美术风格需求.md)。本文是**逐区域的详设**，
> 给美术的具体作业单。

## 一、一条总原则：每个区域要有「一眼可辨的视觉签名」

玩家在大地图上移动时，**必须能靠颜色和剪影判断自己到了哪**，
而不是等看到地名标签才知道。

所以每个区域给一组**主色**，这组色在区域内占比 60% 以上，
且**不与相邻区域撞色**。下面每个区域都标了主色，那是硬要求。

## 二、材质语言

**光靠颜色区分区域是不够的。** 两个区域都用「木屋 ＋ 土路」画，
即使配色不同，玩家还是会把它们认成同一个地方。

所以每个区域还要有一套**独立的材质语言**——地表、植被、建筑三样组合起来，
构成那个区域独有的"物产感"。

### 三类材质的词汇表

美术按这三类出图，**每个区域各挑一组，不共用**：

**一、地表**（`Ground` 层）

| 类型 | 用途 |
|---|---|
| 草地／枯草 | 野外 |
| 土路／夯土 | 道路与空地 |
| 石板／碎石 | 城镇与官道 |
| 泥沼／淤泥 | 水岸与低地 |
| 岩地／碎石坡 | 山地与洞窟 |
| 浅水 | 渡口与溪流 |

**二、植被**（`Decor` 层）

| 类型 | 用途 |
|---|---|
| 松林 | 山地与北向坡 |
| 阔叶林／秋色林 | 丘陵 |
| **竹林** | **南方水乡（后续章节主用）** |
| 芦苇／水草 | 水岸与湿地 |
| 灌木／藤蔓／苔藓 | 阴湿处 |
| 枯树／焦木 | 荒废与火焚处 |

**三、建筑材质**（`Decor` 层的构筑物）

| 组合 | 特征 | 用在哪 |
|---|---|---|
| 木构 ＋ 茅草顶 | 最简陋 | 野外窝棚、山寨外围 |
| 木构 ＋ 青瓦顶 | 江南民居 | 清风驿 |
| **粗原木 ＋ 石基** | 粗犷、军事化 | 黑风寨 |
| **石砌 ＋ 瓦顶** | 厚重、正式 | 官式建筑、寺庙（后续） |
| 夯土 ＋ 木梁 | 北方／西北 | 后续章节 |
| **竹构 ＋ 竹顶** | 轻巧、南方 | 后续章节 |

### 为什么这套词汇表现在就要定

第一章只用到前四种组合，但**后面七章会用到全部**。
现在定下来，美术出第一章资源时就能**顺手把后续要用的类型一起规划**，
不用等到做第三章再回头补一套竹构。

而且这条约束很实际：**相邻区域不能共用同一组材质**，
否则玩家在大地图上会失去方向感——他们会觉得「我是不是走回去了」。

## 三、大地图

### 3.1 尺度与比例

大地图是**跨区域通行**用的，**不做等比尺**。

意思是：清风驿在图上只占一小块，但进去是一整张城镇图；黑风寨同理。
所以大地图上的地标要按**可辨识**来画，不按真实大小——
一个寨门画得和一座城一样大是正常的，因为玩家需要看见它。

### 3.2 图层结构（对应场景的六层）

程序侧的图层已经定好，美术按层出图，**不要混在一起**：

| 层 | 画什么 | 挡路 |
|---|---|---|
| `Ground` | 基础地形：草地、土、石地 | 否 |
| `Decor` | 树、石、建筑、栅栏 | **是**（挡路的格子要勾 `blocked`） |
| `Overlay` | 路面、水面、桥、脚印 | 否 |
| **`Conditional`**（0.32.0 新增） | **只在特定条件下出现的地表**：石隙细径 22 格（拿到藏宝图才显示） | 否 |
| `Fog` | 云雾（未探索区） | 否 |
| `Markers` | 地标图标 | 否 |

**分层的原因**：换瓦片集、调密度、改揭雾范围都是按层改的，
混在一起就得整张重画。

**`Conditional` 与 `Overlay` 的分工（0.32.0）**：`Overlay` 是**一直在**的路面／水面／桥，
程序只会在玩家走到它下面时把它**半透明化**（石隙两处死路的岩檐遮挡就用这一层）；
`Conditional` 是**整层显隐**的地表——石隙那条 22 格碎石细径铺在这里，
拿到 `item_treasure_map` 之前它在地图上不存在（「藏宝图上的一条线」）。

### 3.3 云雾与揭开

**谁一开始就亮着（0.32.0）**：只有**城镇**（清风驿）与**驿站**——它们是默认公开的地点。
其余（落雁坡／黑风寨／山洞／荒村／渡口／石隙）**在地图上完全不存在**，要玩家走到跟前才揭开
（口径见 02 号「大地图探索口径」）。画图时按这条想：**开局那一屏只有城镇与驿站两处是亮的**。

| 状态 | 表现 |
|---|---|
| 未探索（且未揭开） | 云雾完全遮住，只透出地形轮廓的深浅；**没有图标、没有地名** |
| 已探索（已揭开） | 云雾散开，**地名常驻**；图标按类型给（兴趣点不给，见 §3.5） |

**云雾要保留地形轮廓**，不能是纯色块——玩家需要从云缝里看出
「那边好像是山」才会想去探索。纯色块会让探索变成盲猜。

### 3.4 道路网络

主路（清风驿—落雁坡—黑风寨）要**明显宽于支路**，
玩家靠路宽判断哪条是主线。

支路通向兴趣点（山洞、荒村、渡口），**要比主路窄、颜色更浅**——
暗示「这是岔路，不是必经」。

**名单定死（A13，0.31.1 补）**——美术照这个出瓦片，别自己判：

| 类型 | 路线 | 画法 |
|---|---|---|
| **主路（一条）** | **清风驿 → 驿站 → 落雁坡 → 黑风寨** | **全图最宽**。依据是数据：`n_heifengzhai` 的 `unlock_condition=discover_luoyanpo`——**它是从落雁坡被发现出来的**，所以 落雁坡→黑风寨 这一段在主路上 |
| **支路（四条）** | **落雁坡 → 塌陷山洞**／**落雁坡 → 荒村**／**驿站 → 废弃渡口**／**落雁坡西 → 石隙迷窟** | 比主路**窄、颜色更浅**；最后一条只在**持有藏宝图后**才看得见（`n_shixi` 的 `unlock_condition=item_treasure_map`） |

> 其余兴趣点（山洞／荒村／渡口）都从**最近的主路节点**岔出去，**两级路网就够**——
> 不要出现第三条宽度档，玩家分不清。**石隙迷窟那条支路要收得更细**（它是"藏宝图上的一条线"）。

> **指路牌只写目的地与路况，不写方位**（0.32.0 定，Q 清单外的口径）：牌子上的字进 `map_region.signpost_cn`，
> 例如「→ 驿站。出了这镇子，路就得自己认。」。**不许写「东北／东南」这类方位词**——那等于把
> `map_region` 的坐标抄进文案，而坐标是会挪的（0.31.2 刚重排过一次），**下次再挪不会报错**；
> 方向感交给**箭头的形状＋牌子所在的位置**。真要写方位，就必须同一次改坐标时把牌子一起改。
> **支路不上牌**：0.32.0 定了那些地点要玩家自己走出来。

### 3.5 地标尺寸与图标

**城镇必须是最大最显眼的一类。** 玩家在大地图上找的是「能落脚的地方」，
一个小图标和大片建筑轮廓，读懂成本完全不同。

| 类型 | 地形占地 | 图标 | 要点 |
|---|---|---|---|
| **城镇** | **3×3 瓦片（48×48）**，硬下限 2×2 | **48×48** | 地形轮廓 ＋ 建筑剪影，不是单贴一个图标 |
| 副本 | 2×2（32×32） | 32×32 | 寨门／塔楼，有威慑感 |
| 驿站 | 2×2 | 32×32 | 旗杆剪影，与城镇区分 |
| 兴趣点 | 无固定占地 | **不给图标** | 只有地形异常 |

**城镇是「拼出来的地形」，不是「贴上去的图标」**——屋舍、院墙、道路一起构成轮廓，
图标只叠在上面做强调。

**兴趣点不给图标**是玩法要求：探索的乐趣来自「我自己发现了这里」，
给个问号图标就把发现变成了清单核对。

**与「探索后才显示」的关系（0.32.0）**：两件事不冲突——**未探索时地图上连地名都没有**（见 §3.3）；
揭开之后，**兴趣点也只给地名**，靠地形认出来（山体上的洞口／岩缝、焦黑屋舍群、水岸），
`map_region` 里那三个兴趣点的 `icon` 因此**留空**。
**唯一例外是藏宝图指向的石隙迷窟**——19 §5.6 那句「玩家手里有图，图上有位置」仍然成立，
它有图标，值用 **`icon_shixi`**（美术已出 `assets/sprites/icons/icon_shixi.png`，A8 落地）。

**地形要成片（0.31.2，实机反馈）**：兴趣点不许"孤零零一个图标"——**先有成片的地形，再在里面留出入口**。

| 兴趣点 | 地形怎么画 |
|---|---|
| 塌陷山洞／石隙迷窟 | 先铺**成片的山脉**；洞口／岩缝是**山体上的凹陷与裂隙**（不是摆在草地上的一个洞） |
| 荒村 | 几间**塌了顶的焦黑屋舍**成组出现 |
| 废弃渡口 | **水面 ＋ 栈桥残骸 ＋ 芦苇** |

> 这条同时要求**山脉本身要成片、有厚度**——大地图上的山不该是孤立的一个方块，
> 否则"洞开在山里"这件事在视觉上不成立。

**指路牌（0.31.2 新增）**：主路节点附近各一块，**木牌 ＋ 箭头**、朱红小字，
材质与城镇招牌同一套（木构）。**要显眼**（路口或节点入口），按 §一 的"可交互物暖色提亮"。

## 四、逐区域设定

### 4.1 落雁坡

| 项目 | 设定 |
|---|---|
| **视觉签名** | **开阔的金秋草坡**——大面积枯黄与青松的对比 |
| 主色 | 枯黄 `#C8A24A` ＋ 青松 `#3E5A46` |
| 材质 | 草甸地表 ＋ 松林 ＋ 芦苇；构筑只有猎人木棚（原木＋茅草） |
| 地形 | 起伏的草坡，地势开阔、遮挡少 |
| 植被 | 稀疏松林、成片芦苇、红叶灌木 |
| 地标 | 靠主路一侧有几株显眼的孤树（玩家用来定位） |
| 氛围 | 秋、风大、有雁 |

**玩法约束：必须开阔。** 这是大地图上视野最远的一块——
玩家要能看见远处的黑风寨寨门，形成"我要去那里"的目标感。
**不要在这里堆密林**，那会把可视距离压没。

### 4.2 清风驿

| 项目 | 设定 |
|---|---|
| **视觉签名** | **青瓦白墙 ＋ 暖黄灯火**——大地图上唯一的暖色块 |
| 主色 | 青瓦 `#5B6B70` ＋ 白墙 `#D8D2C4` ＋ 灯火 `#E8A33D` |
| 材质 | **青瓦 ＋ 白墙 ＋ 木构梁柱**；石板与夯土铺地；市井杂物用布、竹、陶 |
| 地形 | 平整的土路与石板，市集空地 |
| 建筑 | 民居、商铺、客栈、铁匠铺、校场；青瓦为主 |
| 细节 | 酒旗、灯笼、晒衣、水井、货担 |
| 氛围 | 傍晚、炊烟、有人气 |

**玩法约束：一进镇就要"松一口气"。** 清风驿是安全区，玩家会反复回来，
所以它是**全图唯一的暖色区域**，与野外的青冷形成强对比。
这个对比不是审美选择，是**让玩家一眼确认"我安全了"**。

**校场要显眼。** 木桩是前期唯一的练级点，玩家找不到它就不能开工——
校场要有独立的地面（夯土／沙地）、围栏、兵器架，
**在大地图和小地图上都要能一眼认出来**。

### 4.3 黑风寨

| 项目 | 设定 |
|---|---|
| **视觉签名** | **黑旗 ＋ 火把 ＋ 粗木石墙** |
| 主色 | 深褐木 `#4A3A2C` ＋ 石墙灰 `#6E6A63` ＋ 火把橙 `#D96A28` |
| 材质 | **粗原木 ＋ 毛石石基 ＋ 茅草与木板**；军事化，少装饰 |
| 地形 | 山石台地，逐层抬高 |
| 建筑 | 木栅、望楼、寨门、聚义厅 |
| 细节 | 挂着的黑旗、火盆、兵器架、酒坛、血迹 |

**三层要有递进**，靠环境讲"越往里越危险"：

| 层 | 环境语言 |
|---|---|
| 前寨 | 杂乱：散落的杂物、破损的栅栏、牢房的铁栏 |
| 聚义厅 | 规整：铺开的地毯、成排的兵器架、正中的主座 |
| 后寨 | 压抑：更暗、更窄、火盆更少、装饰更少 |

**火把是主要光源。** 黑风寨整体压暗，靠火把提供暖色亮点。
玩家看到的暖色越少，说明位置越深。

### 4.4 塌陷山洞

| 项目 | 设定 |
|---|---|
| **视觉签名** | **逼仄的青灰岩壁 ＋ 洞口一线天** |
| 主色 | 青灰 `#4E5A5E` ＋ 深黑 `#1E2224` |
| 材质 | 青灰岩壁 ＋ 湿土 ＋ 苔藓；无任何构筑物 |
| 地形 | 窄通道、落石、塌方 |
| 细节 | 岩壁刻痕、骸骨、积水、矿脉反光 |

**玩法约束：这是"秘密通道"，要窄、要暗、要单向。**
它不是一个可以逛的地方，而是「钻过去就是后山」的捷径。
**画得太开阔会让玩家以为这里另有内容。**

### 4.5 荒村

| 项目 | 设定 |
|---|---|
| **视觉签名** | **焦黑断墙 ＋ 枯树 ＋ 无人** |
| 主色 | 焦黑 `#3A3430` ＋ 枯黄 `#8A7A55` ＋ 灰 `#7A7570` |
| 材质 | **焦木 ＋ 塌瓦 ＋ 夯土残墙**；荒废田垄与烧断的梁 |
| 地形 | 荒废的田垄、倒塌的院落 |
| 细节 | 半塌的屋、烧焦的梁、破缸、乌鸦、晾着的破布 |

**玩法约束：要一眼看出"这里出过事"。**
荒村是第一章里唯一有"人祸痕迹"的野外区域，
它的作用是在玩家进黑风寨之前**先给一次情绪铺垫**。

### 4.6 废弃渡口

| 项目 | 设定 |
|---|---|
| **视觉签名** | **灰蓝水汽 ＋ 朽木断桩** |
| 主色 | 灰蓝 `#5A6E7A` ＋ 朽木 `#6B5A46` |
| 材质 | **朽木 ＋ 芦苇 ＋ 淤泥 ＋ 浅水**；断桩与半沉船 |
| 地形 | 河滩、浅水、淤泥 |
| 细节 | 半沉的破船、断掉的栈桥桩、芦苇、晾网 |

**玩法约束：要让玩家"想去看看但去不了"。**
这是第二章的入口，本章不开放。表现上要**看得出还能走**（栈桥残骸、
对岸有轮廓），而不是彻底封死——玩家应该记住这个地方，而不是绕过去。

### 4.7 驿站

| 项目 | 设定 |
|---|---|
| **视觉签名** | **官道旗杆 ＋ 马桩** |
| 主色 | 土黄 `#A89060` ＋ 朱红 `#A83A2E`（旗） |
| 材质 | **夯土墙 ＋ 石铺地 ＋ 木构**；旗用布，拴马用木石 |
| 地形 | 平整的官道、碎石铺地 |
| 细节 | 旗杆、马槽、灯笼、告示牌 |

**驿站是功能点（传送与切难度），要小而明显。**
不需要大，但旗帜要够醒目——玩家在地图上找的就是那面旗。

### 4.8 石隙迷窟

| 项目 | 设定 |
|---|---|
| **视觉签名** | **窄岩缝里的一线天光** |
| 主色 | 青灰岩 `#4A5258` ＋ 暗赭 `#5A4A3C`（缝里的土） ＋ 遗篇幽蓝 `#3E5A7A`（石台的光） |
| 材质 | 青灰岩壁 ＋ 碎石 ＋ 苔藓 ＋ **前朝石台**（唯一的人工痕迹） |
| 地形 | 极窄的岩缝，一条主缝分出几条岔缝 |
| 细节 | 裂缝渗水、风化的刻纹、几具旧骸骨、石台上的残卷 |
| 氛围 | 很久没人来过；安静，只有水滴声 |

**与塌陷山洞要区分开**：两者都是岩洞，但
**塌陷山洞是「塌出来的」，石隙迷窟是「劈出来的」**——
前者的岩壁破碎杂乱，后者的岩壁**笔直、有裂缝**，像是被硬生生劈开的。

**玩法约束：两条死路必须在视觉上「看起来能走」。**

这条是本节最重要的要求。迷宫有两处死路（塌方、空室），
**如果美术把死路画得明显（比如画成一堵墙、一段坍塌），迷宫就不成立了**——
玩家一眼看穿，这个迷宫就只是一个多走两步的走廊。

所以：

| 房间 | 画法 |
|---|---|
| 塌方（死路，但有宝箱） | **要画得像个能进去的地方**，箱子的光甚至要比别处亮一点 |
| 空室（死路） | 要画得像继续往前走会有什么东西 |

**死路的"死"要由玩家走到底才发现，不能由美术提前告诉他。**

## 五、区域对照表

一张表看全局，**相邻区域不许撞主色**：

| 区域 | 主色 | 冷暖 | 明度 | 一句话 |
|---|---|---|---|---|
| 落雁坡 | 枯黄＋青松 | 暖 | 亮 | 草甸／松林 | 开阔秋坡 |
| 清风驿 | 青瓦＋灯火 | **暖** | 亮 | **青瓦＋白墙＋木构** | 唯一的暖色安全区 |
| 黑风寨 | 深褐＋火把 | 冷 | **暗** | **粗原木＋石基** | 森严敌巢 |
| 塌陷山洞 | 青灰＋深黑 | 冷 | **最暗** | 岩＋湿土 | 逼仄密道 |
| 荒村 | 焦黑＋枯黄 | 冷 | 暗 | **焦木＋塌瓦＋夯土** | 人祸遗迹 |
| 废弃渡口 | 灰蓝＋朽木 | 冷 | 中 | **朽木＋芦苇＋淤泥** | 萧条水岸 |
| 驿站 | 土黄＋朱红 | 暖 | 亮 | 夯土＋石铺＋木构 | 官道中继 |

**相邻区域不共用同一组材质**，理由见第二节：玩家会以为「我是不是走回去了」。

**塌陷山洞与石隙迷窟明度相近，靠岩壁形态区分**：前者破碎杂乱（塌出来的），
后者笔直有裂缝（劈出来的）。光也相反——塌陷山洞几乎无光，石隙有一线天光。
