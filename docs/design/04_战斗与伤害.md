# 04 战斗与伤害

## 战斗基本结构

| 项目 | 设定 |
|---|---|
| 形式 | 回合制 |
| 队伍 | 3–4 人，前排／后排站位 |
| 出手顺序 | 由身法决定，高身法先手 |
| 普通战时长 | 30 秒 – 1 分钟 |
| 精英战时长 | 1 – 2 分钟 |
| Boss 战时长 | 3 – 5 分钟 |
| 加速 | 1x / 2x / 4x |
| 自动战斗 | 支持，可设策略（保守／均衡／全力） |

## 三种战斗资源

| 资源 | 说明 |
|---|---|
| 气血 hp | 生命值 |
| 内力 qi | 招式消耗资源 |
| 架势 poise | 破防资源，被打就掉，归零即进入破绽 |

### 核心循环

```
攻架势 ──► 打空 ──► 破绽窗口（1 回合）──► 绝招爆发 ──► 敌方架势重置
```

敌方出招前有一回合**预兆**。玩家可以花行动去"拆招"读招，读出后该招伤害减半并反涨自身架势。

**设计意图**：教玩家"抓破绽"，而不是靠磨血过关。打大寨主时这条机制会被强制体验——他的架势回复极快，不抓破绽就打不动。

## 伤害分类：两个正交的轴

你列的四类是两类东西混在一起，拆成两个轴，既不丢类型，结算也干净。

**轴一 · 结算类型**——决定走哪条公式、能否暴击、是否逐回合。

**轴二 · 系别**——决定吃什么抗性、与敌方相克。

### 伤害类型表

配置见 `damage_type.csv`。

| type_id | 名称 | 结算 | 可暴击 | 可闪避 | 吃外防 | 吃内防 | 结算时机 | 持续 | 层数上限 |
|---|---|---|---|---|---|---|---|---|---|
| dmg_normal | 非暴击直伤 | 直伤 | 否 | 是 | 是 | 否 | 立即 | — | — |
| dmg_crit | 暴击直伤 | 直伤 | 是 | 是 | 是 | 否 | 立即 | — | — |
| dmg_reflect | 反伤 | 直伤 | 否 | 否 | 否 | 否 | 立即 | — | — |
| dot_poison | 中毒 | 持续 | 否 | 否 | 否 | 否 | 回合末 | 3 | 5 |
| dot_burn | 灼伤 | 持续 | 否 | 否 | 否 | 否 | 回合末 | 2 | 3 |
| dot_bleed | 流血 | 持续 | 否 | 是 | 是 | 否 | 回合末 | 4 | 3 |
| dot_internal | 内伤 | 持续 | 否 | 否 | 否 | 否 | 回合末 | 5 | 1 |

`dmg_normal` 和 `dmg_crit` 在结算上共用一条管线，暴击只是一个乘数。分开成两个 type_id 是为了**跳字显示**和**"暴击时触发"这类效果**能挂上去。这样四类伤害落地了，管线还是干净的。

**内伤**是武侠特色位：不吃防御、不可驱散、持续最久，并且**降低目标的内力回复**。它克制拼命堆内力的内功流。

## 系别与相克

| 系别 | 驱动属性 | 说明 |
|---|---|---|
| 外功 external（刚） | 力 | 吃外功防御 |
| 内功 internal（柔） | 智 | 吃内功防御 |

## 伤害结算管线

顺序不能随便改，这里定死。全局常数（防御常数、随机浮动范围、背袭加成等）
配置在 `combat_const.csv`，不写死在代码里。

```
0. 闪避判定：未命中 → 本次伤害为 0，后续全部跳过
1. D = 技能基础值 × 技能倍率(power_ratio) × (1 + 熟练度 × mastery_gain)
2. A = D × (1 + 攻击属性系数)      ← 外功取力，内功取智，奇诡取两者均值
3. C = 直伤且暴击判定成功 ? A × (crit_base_mult + 暴击伤害) : A
4. K = C × 系别相克系数
5. 有效防御 = 目标防御 × (1 - 攻击方穿透率)
   防御减免 = 有效防御 / (有效防御 + def_const + def_level_coeff × 攻击者等级)
   R = K × (1 - 防御减免)
6. B = 格挡判定成功 ? R × (1 - 格挡减伤率) : R
7. M = B × (1 + 增伤总和) × (1 - 减伤率)
8. F = M × 随机浮动(variance_min ~ variance_max)
9. 最终伤害 = floor(F)
```

### 防御减免公式

```
有效防御 = DEF × (1 - 攻击方穿透率)
防御减免 = 有效防御 / (有效防御 + def_const + def_level_coeff × 攻击者等级)
```

`def_const` 默认 60、`def_level_coeff` 默认 20，都在 `combat_const.csv` 里配。

这个式子是防滚雪球的关键。用除法的形式，防御再高也只能趋近于 100% 减免而永远到不了；
分母随等级成长，保证后期不会出现"坦到无解"。

穿透在这里生效：它乘在防御值上而不是减免结果上。穿透 30% 意味着目标的
有效防御只剩七成——对低防御目标几乎无感，对高防御目标收益很大。这是有意的，
穿透的定位就是"破坦"，不是通用增伤。

### 位置纪律

五个环节各自的位置都有理由，改管线时逐条对照：

| 环节 | 位置 | 理由 |
|---|---|---|
| 暴击 | 防御之前 | 先放大再减免，暴击收益才和攻击力挂钩。放最后乘会变成与攻击力无关的固定加成，成长性断掉 |
| 相克 | 防御之前 | 相克修正的是"攻击强度"而非"最终伤害"，放后面会让高防御目标完全免疫相克收益 |
| 穿透 | 防御之前 | 穿透的作用是压低有效防御，必须在计算减免之前介入 |
| 格挡 | 防御之后 | 格挡是独立减伤事件，与防御减免相乘；先算防御，两者才不会互相稀释 |
| 减伤 | 最后 | 终局乘区，稳定按比例削减最终伤害，不受暴击、相克、格挡干扰 |

### 闪避与格挡互斥

同一次攻击只判定一次：**先判闪避**（完全免伤，直接跳到结算），
**未闪避再判格挡**（部分免伤）。

两个都触发的话，坦克堆双属性后近乎无敌；而且每回合判定两次会让战斗节奏变拖沓。
## 持续伤害（DoT）三条规则

### 一、快照制

DoT 的每层伤害在**施加的那一刻**锁定，之后即使增益掉光也照原值跳。

好处是催生"先叠满增益再上毒"的手法，有操作深度；代价是玩家可以卡增益时间做爆发。这是可接受的取舍。

### 二、同源同类叠加层数，刷新时长

同一个敌人身上最多 5 层毒，第 6 次施毒只刷新时间不加层。不同来源的毒独立计算。

### 三、回合末统一结算

不按行动条各自计时，全部在每回合末跳字。**好处是玩家一眼能算清这回合能不能毒死**，代价是失去一点真实感——值得。

### 为什么 DoT 不吃暴击和闪避

这是刻意的：**它是一条"稳定但慢"的输出路线**，和暴击流的"波动但快"形成对比。

刷子游戏里 DoT 的天然劣势是打得慢，所以它必须换来稳定性作为补偿。

## 异常状态

配置见 `status_effect.csv`。

### 一条简化后的规则

**运决定所有异常状态的触发几率，智决定所有异常状态的强度。**

早期草案里我给流血单独配了敏作为触发属性，后来改掉了。四个异常各挂一个不同属性会造成认知负担，统一到运和智之后，玩家只需要记住一句话。

| status_id | 名称 | 关联伤害 | 层数 | 持续 | 可驱散 | 特殊效果 |
|---|---|---|---|---|---|---|
| poison | 中毒 | dot_poison | 5 | 3 | 是 | — |
| burn | 灼伤 | dot_burn | 3 | 2 | 是 | 每层降低目标 5% 外功防御 |
| bleed | 流血 | dot_bleed | 3 | 4 | 是 | 目标换位／移动时额外触发一次 |
| internal | 内伤 | dot_internal | 1 | 5 | 否 | 内力回复减半 |

灼伤削防、流血克制换位、内伤压制内力——四类持续伤害各有战术位，不是四个换名字的"掉血"。

### DoT 在小怪战里的补偿

清小怪时毒还没跳完怪就死了，这是 DoT 在刷子游戏里的天然劣势。

建议加一条**斩杀规则**：目标血量低于 15% 时，其身上剩余的 DoT 层数立即结算。否则毒流玩家刷本会很难受。

## 武学与招式

招式配置见 `skill_base.csv`。每条招式记录：所属武学、系别、伤害类型、倍率、内力消耗、破架势值、攻击段数、附带异常状态。

武学分三层：

| 层 | 说明 |
|---|---|
| 外功 | 招式，装配式，一本秘籍解锁数招，可自由搭配 |
| 内功 | 心法，提供内力上限与被动 |
| 轻功 | 身法，影响行动顺序、闪避、位移 |

武学靠**残页**拼合，集齐同一套还有额外效果。集齐的驱动力比单纯升级强得多。
