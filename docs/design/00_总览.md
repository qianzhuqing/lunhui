# 00 总览

## 一句话定位

武侠回合制 RPG。玩法优先，玩家在开放的区域里自由探索、刷装备、挖隐藏内容；剧情退到很后面，第一章不设主线剧情。

## 设计支柱

**一、玩法优先，探索驱动。** 推进动力不是"我想知道后面发生了什么"，而是"我想打过去""我想刷到那件装备""我想知道那边藏了什么"。第一章只有一句引子，其余全靠玩家自己摸。

**二、自由。** 同一个目标给多条路走。想莽的莽得动，想绕的绕得走，想刷的刷得爽。玩家在一周目内就能以完全不同的顺序体验同一片区域。

**三、明雷为核心遭遇方式。** 敌人在大地图上可见、可绕、可挑。玩家在地图上的走位直接决定战斗开局（背袭／被袭），这是明雷相对暗雷的核心价值。

**四、可刷。** 装备带随机词条，副本可重复挑战，掉落有保底。刷子的循环必须轻松——普通战 30 秒到 1 分钟，可加速、可自动、可扫荡。

## 核心循环

```
        ┌──────────────────────────────────────┐
        │                                      │
        ▼                                      │
   大地图探索 ──► 明雷遭遇／野外事件            │
        │              │                       │
        │              ▼                       │
        │          战斗与掉落 ──────────────────┤
        │              │                       │
        ▼              ▼                       │
   发现新地标 ──► 进入小地图 ──► 副本挑战 ──────┤
        │              │            │          │
        │              │            ▼          │
        │              │       隐藏内容／Boss ──┘
        │              ▼
        └──► 清风驿：打造装备・交悬赏・补给药
```

|---|---|
| 目标总时长 | 20–30 小时（不含多周目；多周目已移出当前计划） |

## 第一章范围

**区域**：江南道・东部

| 地点 | 类型 | 内容 |
|---|---|---|
| 清风驿 | 城镇小地图 | 铁匠铺、药铺、当铺、悬赏板、客栈、NPC |
| 落雁坡 | 大地图野外 | 明雷野怪、采集点、塌陷山洞 |
| 黑风寨外围 | 大地图野外 | 巡逻山贼、瞭望塔、后山密道入口 |
| 荒村 | 大地图兴趣点 | 野外精英、隐藏宝箱 |
| 废弃渡口 | 大地图兴趣点 | 第二章入口，本章不开放 |
| 黑风寨 | 副本小地图 | 前寨／聚义厅／后寨三层＋隐藏层 |
| 塌陷山洞 | 隐藏小地图 | 通往山寨后山 |

**唯一引子**：清风驿告示板写着，沈家小姐被黑风寨掳走，赎金谈崩了。

**唯一目标**：救出沈家小姐。什么时候去、走哪条路、救到人就走还是全清，全自由。

## 多周目

> **暂缓：多周目（NG+）已移出当前计划，不排期。** 下面的设计保留作后续方向的参考，
> 开发侧当前不做周目继承、周目难度轮回与 `ng_plus_config.csv`。

因为第一章没有剧情，多周目不做剧情重演，做成**难度轮回**：

| 周目 | 名称 | 内容 |
|---|---|---|
| 一周目 | 初入江湖 | 正常难度 |
| 二周目 | 重走江湖 | 敌人强化，掉落几率提升，精英新增词缀，隐藏 Boss 开放二阶段 |
| 三周目 | 绝境 | 全敌强化，专属挑战内容，隐藏层开放 |

继承装备、武学、图鉴与图鉴完成度奖励。

**关键规则：难度不改变掉落清单，只改变掉落几率。** 低难度玩家也能刷到最好的东西，只是慢。难度是时间效率的选择，不是内容的门槛。详见 [05_装备与掉落](05_装备与掉落.md)。

## 术语表

| 术语 | 含义 |
|---|---|
| 大地图 | 跨区域通行的世界地图，承载移动、探索、明雷遭遇 |
| 小地图 | 单个地点的场景，分城镇型与副本型 |
| 明雷 | 在大地图或小地图上可见的敌人，可绕、可挑、可背袭 |
| 背袭 | 从敌人背后接触进入战斗，我方先手 |
| 架势 | 战斗中的破防资源，被打掉，归零即进入破绽 |
| 破绽 | 架势归零后的窗口状态，此时受绝招伤害大幅提高 |
| 刷子元素 | 可重复挑战副本、追求随机词条装备的循环 |
| 前尘点数 | 跨周目货币，用于解锁前尘剧情（后续设计） |
