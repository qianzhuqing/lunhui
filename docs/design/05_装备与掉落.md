# 05 装备与掉落

## 装备槽位

共 7 类槽位，戒指可戴两枚，其余各一。定义见 `equip_slot_def.csv`。

| slot_id | 名称 | 数量 | 主要属性 |
|---|---|---|---|
| `weapon` | 武器 | 1 | 外功／内功攻击，决定可用招式 |
| `body` | 身体 | 1 | 外功防御、气血 |
| `belt` | 腰带 | 1 | 气血、内力 |
| `shoulder` | 肩部 | 1 | 防御、格挡 |
| `legs` | 下装 | 1 | 身法、防御 |
| `ring` | 戒指 | 2 | 属性点、暴击、穿透 |
| `necklace` | 项链 | 1 | 气血、减伤、异常 |

装备本体见 `equip_base.csv`。

### 武器类型

只有四种：**剑、拳、刀、枪**。定义见 `weapon_type_def.csv`。

| weapon_type | 名称 | 倾向属性 | 定位 |
|---|---|---|---|
| `sword` | 剑 | 敏・智 | 招式均衡 |
| `fist` | 拳 | 力・体 | 近身，破架势高 |
| `blade` | 刀 | 力 | 刚猛，单段高伤 |
| `spear` | 枪 | 力・体 | 长兵，攻击距离远 |

武器类型只决定倾向与默认系别，**具体系别以每件装备自己的 `element` 为准**。
例如乌木拳套是内功拳——拳法不必然走外功，这给了内功流一条武器出路。

### 装备的基础属性

每件装备都有基础属性，分两组写在 `equip_base.csv` 里：

| 列 | 含义 |
|---|---|
| `attr_*` | 直接加属性点，会再经 `attr_to_stat` 换算成派生数值 |
| `bonus_*` | 直接加派生数值，去掉前缀即 `stat_def.stat_id` |

**某些槽位的个性用属性点表达，而不是新开派生数值列。**
比如腰带不写 `bonus_qi_max`，而是给 `attr_int`——智本身就带内力上限，
这样腰带对毒功流和内功流同时有意义，也避免了每加一个槽位就得改表结构。

判断标准很简单：**能用属性点表达的，就不要新开列。**
只有属性点表达不了的（暴击率、穿透率、格挡减伤）才用 `bonus_*`。

## 词条系统

装备带随机词条，**词条是刷的核心**：同样一把刀，可以刷出加身法、加内力回复、带毒、带破架势——**刷的是搭配，不只是数值**。

词条池见 `affix_pool.csv`。词条按槽位限定，不同稀有度的词条数量上限不同。

### 词条的两条纪律

**词条按槽位限定。** 武器不该刷出"内力回复"，护甲不该刷出"破架势"。跨界词条会让装备失去个性。

**词条数值区间要窄。** 同一词条上下限差 3 倍以上，玩家就会无限重刷。控制在 1.5 倍以内比较健康。

## 掉落分层

| 敌人层级 | 掉落 |
|---|---|
| 普通喽啰 | 铜钱、材料、低概率凡品 |
| 精英头目 | 保底一件良品，小概率珍品，掉武学残页 |
| 章节 Boss | **首杀必掉**固定珍品武器 |
| 隐藏 Boss | 必掉隐藏武学与传世装备 |

配置见 `drop_table.csv`。每个敌人通过 `drop_group` 引用一组掉落行，每组可包含多个独立判定的掉落槽。

### 首杀 vs 重复刷

这两种奖励的职能完全不同：

| | 首杀 | 重复刷 |
|---|---|---|
| 目的 | 确定的惊喜 | 随机的追求 |
| 内容 | 固定 unique 掉落 | 同部位随机词条 |
| 保底 | 必掉 | 累计计数保底 |

**首杀给"确定的惊喜"，重复刷给"随机的追求"**——这是刷子游戏的标准解法，也是这套体系能撑住二十小时的原因。

## 难度与掉落

### 核心规则

**掉落清单全局唯一。难度不改变清单，只改变掉落几率。**

这条规则的好处很实在：**低难度玩家也能刷到最好的东西**，只是慢。

难度变成"时间效率的选择"而不是"内容的门槛"，这对自由探索的调性非常合适，也避免玩家为了拿某件装备被迫去打不喜欢的难度。

配置见 `difficulty_config.csv`（敌方数值倍率）与 `difficulty_drop_rate.csv`（掉率倍率）。

### 掉率倍率示意

| 稀有度 | 普通 | 困难 | 绝境 |
|---|---|---|---|
| 凡品 | ×1.0 | ×1.5 | ×2.0 |
| 良品 | ×1.0 | ×1.5 | ×2.2 |
| 珍品 | ×1.0 | ×1.75 | ×2.75 |
| 奇珍 | ×1.0 | ×2.0 | ×3.75 |
| 传世 | ×1.0 | ×2.67 | ×6.67 |

越低概率的稀有度，高难度下的倍率越高。这样高难度"单场更爽"，低难度"刷得更快"。

### 必须提前防的坑

**如果高难度掉率更高，理性玩家都会开最高难度刷，低难度就失去意义了。**

解法是让难度提升带来的掉率增幅**小于**战斗时长和翻车率的增幅。高难度单场掉率高，但单位时间的期望收益要和低难度接近。

| 难度 | 补偿机制 |
|---|---|
| 普通 | 战斗快，自动战斗稳定，可扫荡，单位时间击杀数多 |
| 困难 | 单场收获更爽，有一定挑战感 |
| 绝境 | 极限挑战，专属成就，掉率最高但极易翻车 |

**两边效率拉平，玩家才会按喜好选，而不是按数学选。** 这条需要在实测中用数据反复校准。

## 保底机制

**纯随机会劝退，保底是刷子游戏的底线配置。**

| 规则 | 设定 |
|---|---|
| 触发 | 某稀有物累积击杀 N 次仍未掉落，第 N 次必出 |
| 计数单位 | 每个 `drop_group` 独立计数 |
| 跨难度 | 继承 |
| 跨周目 | 继承（**暂缓**：多周目已移出当前计划，先不做） |
| 建议 N 值 | 珍品 20 次，奇珍 60 次，传世 150 次 |

保底计数器要跨难度继承，否则玩家切换难度时会有心理负担。跨周目继承随多周目一起暂缓。

## 运属性对掉落的影响

运属性的 `drop_rate` 派生数值会小幅提升全队掉落机缘（每点 0.3%，上限 25%）。

这会催生"换装刷"——玩家穿运装刷本，刷完换回输出装。这本身是经典设计，但要有意为之：

- 保守方案：把影响压到 25% 上限以内，只当作锦上添花
- 进取方案：大方承认，做成一条正经的"盗宝流" build

**当前采用保守方案。** 如果后续要放开，改 `attr_to_stat.csv` 里 `drop_rate` 的 `cap` 即可。

## 商店与经济

清风驿有四家店，功能按建筑划分。定义见 `building_def.csv`，货架见 `shop_stock.csv`。

| 建筑 | 卖什么 | 附加服务 |
|---|---|---|
| 杂货铺 | 材料、白板饰品 | — |
| 酒楼 | 非战斗回血道具 | — |
| 医馆 | 战斗中回血道具 | 花钱治疗 |
| 铁匠铺 | 白板装备 | — |

**所有店铺都同时提供买入与卖出。** 没有只买不卖的店，也没有只卖不买的店。

### 两种回血道具必须分开

这是酒楼和医馆的职能分界，不能混：

| 类型 | `use_context` | 使用场合 | 特点 | 售卖点 |
|---|---|---|---|---|
| 非战斗回血 | `field` | 只能在大地图与城镇使用 | 回复量大、便宜 | 酒楼 |
| 战斗中回血 | `battle` | 可在战斗中使用 | 回复量小、贵 | 医馆 |

如果战斗中道具又便宜又能用，非战斗道具就没人买；反过来也一样。
价格差必须反映"战斗中能用"这件事的价值。

### 治疗服务

医馆提供花钱治疗，价格按缺失的气血计算：

```
治疗费用 = 缺失气血 × service_price
```

`service_price` 配在 `building_def.csv`，当前为每点气血 2 文。
治疗不受药品种类限制，是给"懒得吃药"的玩家准备的便利选项。

### 商品与存档

**商品清单来自配表，交易状态写进存档。**

| 内容 | 来源 |
|---|---|
| 卖什么、什么价、限不限量 | `shop_stock.csv`（配表） |
| 玩家累计买入次数 | 存档 |
| 玩家卖出的物品（回购列表） | 存档 |
| 限量商品的剩余数量 | 存档 |

存档结构：

```
shop_state: {
  "<building_id>": {
	"purchased": { "<item_id>": <累计买入次数> },
	"buyback":   [ { item_id, qty, price } ]
  }
}
```

四条规则：

- `stock_limit` 为 0 表示无限量。**第一章所有货架都是无限量**，字段先留着，
  限量商品（稀有材料、限购图纸）留到后续章节再启用。
- **卖出价一律低于买入价**，差价即交易税。别做成一买一卖不亏钱，
  否则玩家会在两家店之间刷钱。
- **玩家卖出的装备不进店铺常规货架，只进回购列表。** 否则玩家把垃圾装备
  卖给铁匠铺，下次进店却看见它摆在货架上——观感很怪。
- 回购列表要有上限（建议 20 条），满了挤掉最早的。

## 刷子循环与节奏

```
探索野图攒材料 ──► 清风驿铁匠打造／强化 ──► 挑战副本拿掉落
		▲                                          │
		└──────── 变强后去挖隐藏内容 ◄──────────────┘
```

节奏锚点：

| 项目 | 目标 |
|---|---|
| 清一圈落雁坡 | 3–5 分钟 |
| 普通战 | 30 秒 – 1 分钟 |
| 精英战 | 1 – 2 分钟 |
| Boss 战 | 3 – 5 分钟 |
| 单次完整副本 | 15–25 分钟 |

**如果刷一场小兵要两分钟，玩家撑不过三小时。** 所有节奏设计都要服务于"重复但不烦"。
