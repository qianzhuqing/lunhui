# 03 副本：黑风寨

## 总览

| 项目 | 设定 |
|---|---|
| 所属章节 | 第一章 |
| 类型 | 章节主副本，可重复挑战 |
| 层数 | 3 层 + 1 隐藏层 |
| 等级区间 | 3 级（前寨）～ 15 级（隐藏 Boss） |
| 位置 | 大地图・黑风寨外围 |
| 目的 | 救出沈家小姐 |
| 完成度项 | 宝箱、隐藏房间、隐藏 Boss、事件 |

## 目标与动机

清风驿告示板：沈家小姐被黑风寨掳走，赎金谈崩了。

整个副本只有这一个目标——**救出沈家小姐**。什么时候来、走哪条路、救到人就走还是全清，全自由。

**「救到人就走」仍然成立**（0.29.0）：主线有一条薄主线（见 [20_第一章剧情](20_第一章剧情.md)），
但地牢里与沈雁回交互**不是判定门槛**；救到人直接回城复命，第一章照样结束，
只是少知道一段真相（沉银案那条暗线）。**但主线本身是通往第二章的必经之路**——
「薄」指不给门锁，不指可以没有；能跳过的是**深度**（暗线、支线、大寨主），不是**救人这件事**。

## 分层结构

```
黑风寨（副本小地图）
├─ 第一层 前寨        lv 3–5    喽啰・陷阱・地牢・密室
│   └─ 隐藏：三火盆密室（顺序谜题）
│   └─ 隐藏：牢房深处 → 醉刀客入口
├─ 第二层 聚义厅      lv 5–8    精英头目 ×2・毒堂・宝库
│   └─ 隐藏：毒杀毒手 → 独门秘籍
├─ 第三层 后寨        lv 8–12   章节 Boss：大寨主
│   └─ 隐藏：全程潜行不惊动 → 额外剧情与宝箱
└─ 隐藏层 后山地牢    lv 12–15  隐藏 Boss：醉刀客
	└─ 入口在塌陷山洞，由后山密道进入
```

## 三条上山路线

同一个"救人"目标给三条路，玩家自己选：

| 路线 | 前置条件 | 特点 |
|---|---|---|
| 正门强攻 | 无 | 战斗最多，推进最直接，适合刷装备 |
| 后山密道 | 在落雁坡塌陷山洞拿到铁镐并挖通 | 敌人更少但更强，可绕开前寨直插后寨 |
| 伪装混入 | 刷到「黑风寨号衣」+「黑风寨腰牌」 | 进门不触发战斗，被识破则陷入包围战 |

三条路都通向地牢，但路上拿到的东西不一样。**这就是"探索推进"的意思——不是玩家找不到路，是玩家能找到好几条路。**

## 各层房间流程

房间配置见 `dungeon_room.csv`。

### 第一层 前寨（lv 3–5）

| 房间 | 类型 | 内容 | 出口 |
|---|---|---|---|
| 寨门 | 入口 | 首次进入触发对话 | 前院、哨道 |
| 前院 | 战斗 | 喽啰 ×3 | 柴房、哨道 |
| 柴房 | 宝箱 | 铜箱（铁镐、铁矿石） | 前院 |
| 哨道 | 陷阱 | 落石陷阱，可通过或拆解 | 地牢、火盆厅 |
| 火盆厅 | 隐藏 | 三个火盆，按序点燃开密室 | 火盆密室 |
| 火盆密室 | 宝箱 | 银箱（前代寨主遗物） | 火盆厅 |
| 地牢 | 剧情 | **沈家小姐在此**，救出即完成主目标 | 牢房深处 |
| 牢房深处 | 隐藏 | 疯癫老者（醉刀客），需要酒葫芦 | — |

### 第二层 聚义厅（lv 5–8）

从地牢后门进入，也可以从后山密道反向进入。

| 房间 | 类型 | 内容 | 出口 |
|---|---|---|---|
| 石阶 | 入口 | 无战斗 | 演武场、毒堂 |
| 演武场 | 精英 | 黑风刀客 ×1 + 喽啰 ×2 | 聚义厅 |
| 毒堂 | 精英 | 毒手 ×1（可毒杀，见隐藏内容） | 聚义厅、密道口 |
| 密道口 | 隐藏 | 通往后寨的捷径（需先开启） | 后寨 |
| 聚义厅 | 精英 | 巡山小头目 ×2 | 宝库、后寨 |
| 宝库 | 宝箱 | 金箱（珍品装备保底） | 聚义厅 |

### 第三层 后寨（lv 8–12）

| 房间 | 类型 | 内容 | 出口 |
|---|---|---|---|
| 后寨门 | 入口 | 若全程潜行未被发现，守卫在此投降 | 巡逻道、后山地牢 |
| 巡逻道 | 战斗 | 寨中精锐 ×3 | 后寨 |
| 后山地牢 | 隐藏 | 醉刀客（隐藏 Boss） | — |
| 后寨大堂 | Boss | **大寨主** | 结束 |

## Boss 设计

### 章节 Boss：大寨主（lv 12）

| 项目 | 设定 |
|---|---|
| 属性 | 外功为主，高破架势 |
| 血量 | 常规，不堆数值 |
| 核心机制 | 架势回复极快，必须在破绽窗口内打满伤害 |
| 招式 | 斩风（单体高伤）、横扫（三段群攻） |
| 首杀奖励 | 固定掉落珍品武器「黑风刀」 |
| 重复掉落 | 同部位随机词条装备 |

设计意图：教玩家"抓破绽"这件事，而不是靠磨血过关。

### 隐藏 Boss：醉刀客（lv 15）

| 项目 | 设定 |
|---|---|
| 触发 | 在牢房深处给老者酒葫芦 |
| 属性 | 奇诡（奇），吃防御少，绕开玩家的外防堆叠 |
| 特点 | 二阶段会切换为内功系，逼玩家改变输出手段 |
| 招式 | 酒中刀（高伤＋内伤）、醉步（闪避大幅提升） |
| 掉落 | 隐藏武学《醉里乾坤》残卷 + 传世刀「锈月」 |
| 二周目 | 开放二阶段变招，掉落追加词条 |

**错过他就是错过了。** 一周目基本不可能全找到，这是刻意的。

## 隐藏内容

第一章放七个层次的隐藏内容，让爱挖的玩家有东西挖。配置见 `hidden_trigger.csv`。

| # | 名称 | 类型 | 触发条件 | 奖励 |
|---|---|---|---|---|
| 1 | 醉刀客 | 道具 | 把酒葫芦给牢房深处的老者 | 隐藏 Boss + 传世装备 |
| 2 | 后山密道 | 空间 | 在塌陷山洞用铁镐继续往里挖 | 通往山寨后山的捷径 |
| 3 | 三火盆密室 | 顺序 | 按特定次序点燃前寨三个火盆 | 前代寨主遗物（固定词条头部装备） |
| 4 | 潜行入寨 | 行为 | 全程潜行，不惊动任何守卫摸进后寨 | 额外剧情 + 密室宝箱 |
| 5 | 毒杀毒手 | 击杀方式 | 用毒酒阴死聚义厅的毒手 | 独门毒功秘籍（正面打死不掉） |
| 6 | 宝箱全开 | 完整度 | 前寨宝箱全部开启 | 墙上浮现隐藏门 |
| 7 | 锈剑共鸣 | 携带物 | 背包带锈剑进入聚义厅 | 剑气事件，解锁一剑式 |

### 设计意图

七种"钥匙"难度不同：

| 难度 | 钥匙类型 | 玩家行为 |
|---|---|---|
| 低 | 道具、空间 | 找到就行 |
| 中 | 顺序、击杀方式 | 得动脑 |
| 高 | 行为、完整度 | 得练、得耐心 |

玩家的探索深度不同，拿到的回报也不同。

### 隐藏内容的线索来源

线索必须能被找到，否则就是"猜谜"。每条隐藏至少给两个线索来源：

| 隐藏 | 线索来源 |
|---|---|
| 醉刀客 | 地牢老者的自言自语；当铺老板提到"寨里关着个疯子" |
| 后山密道 | 樵夫抱怨山后会塌方；塌陷山洞里的骸骨 |
| 三火盆 | 聚义厅墙上挂歪的一幅画；山寨喽啰的闲聊 |
| 潜行入寨 | 悬赏板提到山寨守卫松懈；守卫换防的规律 |
| 毒杀毒手 | 毒堂里的药罐；药铺老板提到"毒酒" |
| 宝箱全开 | 副本完成度界面直接显示进度 |
| 锈剑共鸣 | 荒野锈剑的拾取描述；聚义厅门上的剑痕 |

## 商业与重复性

| 项目 | 设定 |
|---|---|
| 救出人之后 | 山寨不解散，随时可以回来刷 |
| 重复刷 | 每次重置敌人、宝箱、精英词缀 |
| 已通关层 | 可扫荡（仅结算掉落） |
| 难度 | 可在大地图任意驿站切换 |

**救出人之后山寨仍然保留**，这是第一章的长期内容底座。否则玩家打完就没得刷了。

## 完成度

副本界面显示完成度，包含：

- 宝箱开启数 / 总数
- 隐藏房间进入数 / 总数
- 隐藏 Boss 是否击败
- 事件是否触发

完成度不影响奖励，只作为玩家的追求目标与炫耀项。
