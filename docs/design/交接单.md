## 六、怎么核对

```powershell
powershell -ExecutionPolicy Bypass -File tools\validate_tables.ps1
```

设计侧这条每次都是绿的（0 错误）。它**只能验表与文档的一致性**，
验不了程序侧；程序侧那套走 `tools\run_all_checks.bat`。

设计侧最近新增的校验：

- 非中立敌人**一招都不会** → 报错；**只会一招** → 警告
- 数值型 buff 没有加成行 → 报错
- 套装档位超过成员数 → 报错
- 内功缺运功 grant → 报错
- `feature_toggle` 的 `desc` 没写清 0/1 各是什么 → 警告
- 属性表一个可加点项都没有 → 报错
- **敌人装备武器与招式不匹配 → 报错**（本轮新增；加上时抓到 4 处，屠夫一招都出不了）
- `skill_base.source_type=story` 指向不存在的剧情节点 → 报错（本轮新增）
