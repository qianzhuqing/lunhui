## 一、开工前必须知道的四条硬约定

这几条都是踩过坑才定下的（`docs/dev/框架说明.md` 决策 42）：

1. **进图落点用地编自己放的 `Characters/player_spawn`**——不要按房间猜入口。
2. **房间落点取 `bounds` 矩形中心**——房间节点位置是矩形**左上角**，站角上会被墙推出去、`current_room_id()` 认不到房间。
3. **出口必须"先走出去一次"才武装**——出生点压在 `Exit_` 位点上是**合法摆法**（清风驿就是），否则一进城就被弹回大地图。
4. **改名要一次到位**——位点名就是代码/表里的契约。**NPC 位点按 id 绑优先**（`npc_<npc_id>`），
   占位名 `npc_slot_0N` 是**按编号顺序**映射的：**位点数 > 该场景 NPC 数时，多出来的那个必然绑不到人**（会让玩家觉得"按 Q 没反应"）。

## 四、**当前这一批：大地图重建**（0.31.2，用户实机反馈）

用户原话：「大地图太小了／洞穴之类的希望能融入到山体中，而不是孤零零的放个图标／各个区域之间有一定的距离／
大地图不需要那么多阻挡角色前进的障碍物／地图点到地图点之间增加专门的路／最好再增加指路牌」。

| 要做 | 规格 |
|---|---|
| **画布** | **2048×1536 px（64×48 格）**（原 1024×768＝约一张屏） |
| **8 个节点坐标** | `map_region.pos_x/pos_y` **已改**（清风驿 350,1050／驿站 800,800／落雁坡 1250,1100／黑风寨 1750,700／塌陷山洞 1400,1300／荒村 1850,1250／废弃渡口 300,1400／石隙迷窟 750,1250） |
| **路网** | **主路 1 条（清风驿→驿站→落雁坡→黑风寨）＋支路 4 条**（落雁坡→山洞／落雁坡→荒村／**驿站→渡口**／**落雁坡西→石隙**）。**连续可辨的路面、节点连着节点**（名单以 16 §3.4 为准） |
| **去阻挡** | 主路及两侧**保持开阔**；阻挡只在**区域边界**且用"像墙其实是山／水"的自然边界；**禁止**在地图中央／路口／节点附近散布树丛石块栅栏 |
| **兴趣点融入地形** | 山洞／石隙**开在山体上**（山脉先成片、有厚度）、荒村＝焦黑屋舍群、渡口＝水岸。**兴趣点不摆图标**（16 §3.5「兴趣点不给图标」）——**唯一例外是石隙迷窟**：藏宝图上画着它，给 `icon_shixi`（0.32.0 定） |
| **指路牌** | 主路 4 个节点附近各一块，位点 **`Sign_<node_id>`**，放显眼处（路口／节点入口） |
| **连带重摆** | 明雷 **17 位点**、巡逻 **3 条路径**、大地图 **7 处判定位点**——旧坐标是按 1024×768 摆的 |

> **相机默认 2× 放大**（一屏约 16×9 格，归程序）——**摆图时按"一屏 16×9 格"想构图**：
> 主路要在一屏内看得出走向，山脉要几屏才连得成"山"。

> **山怎么铺——正本在 `docs/dev/地图搭建说明.md` §「大地图的山（0.31.2：给地编的坐标与铺法）」**（美术写的，2026-10-04 交付）。
> 要点：① 图集坐标与 `tools/mapgen/map_kit.gd` 的 `T_MTN_*`／`T_CAVE_RECESS`／`T_CRACK_MOUTH`／`T_SIGNPOST` 一一对应；
> ② **一层山至少铺 2–3 屏**（**孤立一格山 = 又变回"摆在地上的图标"**）；
> ③ **洞口必须嵌在山体里**（四周是山、洞口那格是开口）；④ **山体／山峰／路牌挡路，两个洞口不挡路**。
> 美术踩过的坑也记在那儿了：**整片同一个色会铺成一面灰墙**——厚度靠**纵向明暗＋沟壑＋山脊不等高**，
> 所以别只铺一层：2–3 屏 ＋ 内部 `C`/`C2` 交替 ＋ 偶尔插两座山峰，才是"山"。

### 追加（0.32.0，2026-10-04）：探索口径 ＋ 三条拍板

**A. 开局只亮两处。** 用户口径：「大地图除了城镇等默认公开的地点，其他都需要额外探索才能知道入口，
地图上才显示」。于是 **只有清风驿（城镇）与驿站**默认公开；**落雁坡改成 `proximity_5`**（要走近才揭开），
黑风寨／山洞／荒村／渡口／石隙 照旧要探索。**摆图时注意**：开局那一屏只有清风驿与驿站是亮的，
其余都在雾里；`fog_cells` 的初始值会比以前大。

**B. 石隙细径随藏宝图一起隐藏 —— 定了，要隐藏。**
`16 §3.2` 的分层表**加第 5 层 `Conditional`（条件地表）**：那 22 格碎石细径铺在这一层，
程序按 `item_treasure_map` 整层显示／隐藏。`Ground／Decor／Overlay／Fog` 四层不动。
`verify_maps` 与 `test_map_assets` 要认这一层（程序侧会跟）。

**C. 两处死路选「岩檐遮挡」（方案 ①）。**
岔缝**内段**压 `T_ROCK_EAVE` 到 **`Overlay`** 层（不是 `Conditional`）——程序把 `Overlay`
在**玩家位于其下方时半透明化**，这正是 07 §节点结构原文写的「玩家走到下面时半透明」。
**不选方案 ②（岔缝拉到 ≥30 格）**：那段路枯燥，还要把石隙画布从 36×26 格撑大。
两条**不管选哪个都要守**的规矩照旧：不给「死路专用」瓦片、真路与死路的缝宽必须一致（A9）。
