# 02 地图与明雷

## 设计变更：大地图明雷改为开关控制（2026-10-03）

**大地图默认不放会触发战斗的敌人；战斗默认只发生在小地图里。**

但这个机制**不删，改成开关**——`feature_toggle.csv` 的 `overworld_roaming_enemy`：

| 取值 | 行为 |
|---|---|
| `0`（默认） | 大地图不出现明雷，纯探索与通行 |
| `1` | 大地图照旧出现明雷（警戒圈／追击／背袭／巡逻全部生效） |

理由是这套东西已经完整实现并验证过（`src/world/roaming_enemy.gd`、大地图位点、
闭环里的明雷战斗段），删掉要动 12 个代码文件与 6 份文档；
而**留着开关的成本只是一个二进制位**。默认关，等用户反馈再定长期口径。

改动的动机是把两层地图的职责切得更干净：大地图管「去哪里、发现什么」，
小地图管「在那里打什么」。

### 改后是什么样

| | 大地图 | 小地图 |
|---|---|---|
| 战斗 | **无** | 全部战斗都在这里 |
| 内容 | 移动、发现地标、兴趣点、事件判定、采集 | 副本房间战、精英、Boss、宝箱 |
| 敌人 | 一个都没有 | 房间敌人（仍可见、仍需走位） |

### 保留什么、去掉什么

**保留**：小地图里的房间敌人照旧（可见、可按房间配置队伍）。
「明雷」作为**小地图内的敌人呈现方式**继续存在，只是不再出现在大地图上。

**去掉**：大地图上的明雷位点、警戒圈、追击、背袭、被追击抓上、巡逻路线、威胁色环、
重生计时。这些机制在大地图上没有承载对象了。

### 内容迁移

原本靠明雷出现的野外敌人不能直接丢掉，按这个口径处理：

| 原明雷 | 处理 |
|---|---|
| 巡山兵（`en_bd_scout`） | 移进黑风寨前寨的房间队伍 |
| 独目狼（`en_bd_lone_wolf`） | 移进塌陷山洞（小地图，原本没有敌人） |
| 采药人（`en_herbalist`） | **本来就是非战斗中立单位**，改为纯事件判定点（`ev_herbalist_help` 已在表里），敌人行删除 |
| 野狼／野猪 | 第一章不再出现，数据保留待后续章节当副本敌人用 |
| 睡着的醉汉 | 第一章不再出现 |
| 山贼巡山队／换防队／瞭望塔弓手／寨门哨兵 | 前两类删掉（寨内已有守军）；瞭望塔弓手与寨门哨兵本来就是寨门防御，并入黑风寨外围的副本入口表现 |

### roaming_spawn 保留

`roaming_spawn.csv` **不删**。开关打开时它照旧是大地图明雷的唯一数据源；
开关关闭时，这张表只是暂时没有消费者。

配套的代码路径同样保留，只加一个前置判断：`overworld_controller._spawn_enemies()`
在开关为 0 时直接返回。地编的地图位点、`verify_maps` 的校验、闭环里的明雷战斗段
**全都不用动**——开关打开时它们照旧跑。

内容迁移（巡山兵／独目狼／采药人怎么处理）也**一并撤销**：明雷还在，没必要挪。

## 双层地图结构

核心是**职责切分**：大地图管"去哪里"，小地图管"在那里做什么"。

| | 大地图 | 小地图 |
|---|---|---|
| 作用 | 跨区域通行、探索、发现 | 城镇交互 / 副本战斗 |
| 尺度 | 整个州府／区域 | 单个地点 |
| 战斗 | 明雷遭遇 + 固定事件点 | 副本内可见敌人 |
| 主要内容 | 移动、发现兴趣点、触发野外事件 | 打怪、掉落、解谜、隐藏房间 |
| 目标 | 找到入口 | 通过、全清、挖隐藏 |
| 完成度 | 区域探索度 | 地点完成度（宝箱／隐藏／事件） |

## 大地图

玩家在大地图上以小人移动，跨区域赶路。地图上散布三类东西：

**固定地标**——清风驿、黑风寨、渡口、荒村，进得去的小地图入口。

**明雷遭遇**——拦路的山贼小队、野狼群。看得见、可以绕开，想刷就撞上去。

**兴趣点**——无标记的异常地形、枯树、水潭、塌方。玩家自己凑过去看看有什么。

### 探索呈现

已探索的地标显示在地图上，未探索的部分用云雾盖着，走进去才揭开。**玩家的地图是自己走出来的，不是系统给的**，这样"探索推进"才有实感。

地图上不放任务箭头，只放兴趣点。清风驿的悬赏板是主要信息源，但只给方向不给坐标。

### 移动

步行 + 驿站传送（发现驿站后解锁），后期可以加轻功／坐骑提速。

**不建议加体力值。** 赶路受限制和自由探索的调性是冲突的。

### 大地图也要藏东西

野外精英、隐藏洞穴、特定条件触发的事件。**不是所有内容都在副本里**，否则大地图会退化成一条走廊。

## 小地图

### 城镇型

无战斗，纯交互：铁匠铺、药铺、当铺、告示板、客栈、可聊的 NPC。玩家在这里接悬赏、打造装备、听线索。

城镇是刷子循环的中转站，玩家会反复回来，所以 NPC 对话要有余量，别两句话就掏空了。

### 副本型

战斗、陷阱、宝箱、分支路线、隐藏房间。每张副本小地图记录**完成度**（宝箱全开？隐藏房间进过？），给全清玩家一个追求目标。

副本内敌人同样可见，但**取消追击行为**（房间内原地驻守）。进门瞬间从侧面绕过去，可以拿到突袭开局。

## 两层之间的衔接

```
大地图点地标 ──► 进入小地图 ──► 小地图内活动 ──► 返回大地图原位置
									  │
									  └─ 副本中途可随时退出，进度保留到本层
```

已通关的小地图可以随时重进重刷。

### 存档规则

| 场景 | 规则 |
|---|---|
| 城镇 | 存档点，可自由存读 |
| 大地图 | 自动存档（切换小地图时） |
| 副本内 | 自动存档，退出重进不掉本层进度 |
| 战斗中 | **不允许读档** |

战斗中禁止读档是必须的。否则刷子玩法会被 S/L 玩坏——高难度下玩家会一路读档刷稀有掉落，掉率设计就白做了。

## 明雷系统

**核心原则：玩家在地图上怎么走位，直接决定战斗怎么开局。** 明雷不是随机遭遇的替代品，它把战术判断提前到战斗之前。

### 五种行为模式

| 类型 | 行为 | 玩家对策 |
|---|---|---|
| 驻守 idle | 原地不动，守路口、守宝箱 | 打掉，或另找路 |
| 巡逻 patrol | 固定路线往返 | 卡时间差穿过去 |
| 游荡 wander | 小范围随机走动 | 看运气，嫌烦就清 |
| 追击 chase | 有警戒圈，进圈就追 | 跑，或者迎战 |
| 沉睡 sleep | 不主动，被打才醒 | 绕开省资源 |

### 接触结果

同一个敌人，从不同方向接触，开局完全不同：

| 接触方式 | 战斗开局 |
|---|---|
| 正面撞上 | 正常开战，出手顺序按身法 |
| 从背后接触 | 我方全体先手一回合，敌方架势初始值降低 30% |
| 背后接触沉睡敌人 | 奇袭，首回合伤害 +50%，敌方无防备 |
| 进入追击型警戒圈被发现 | 敌方先手，我方首回合受创 |
| 被追击抓到 | 敌方先手，且第一回合无法逃跑 |

### 潜行

按住潜行键进入潜行状态（移速降至 60%，被发现判定降低）。从敌人背后接触即触发奇袭。潜行失败进入追击流程。

这套操作层让"后山密道"路线从"选了就过"变成"选了还得走位"，也让不想打的玩家有明确手段绕开。

### 威胁标示

每个明雷头顶带颜色环，玩家一眼能规划路线：

| 颜色 | 含义 |
|---|---|
| 绿 | 明显弱于我方 |
| 黄 | 与我方相当 |
| 红 | 危险，需要准备 |
| 紫 | 野战不可挑战，必须组队或充分准备 |

**明雷相对暗雷最大的价值就是这个——玩家能挑着打。** 刷子玩法的前提是"我能选定目标"，暗雷做不到。

### 小队配置与掉落

大地图上的明雷是**小队**，不是单个怪。配置决定掉落池：

| 队伍类型 | 掉落偏向 |
|---|---|
| 山贼刀队 | 武器、强化材料 |
| 山贼弓队 | 暗器、敏捷向词条 |
| 混合队（刀＋弓＋算命先生） | 武学残页 |

想刷什么就去找对应队伍。精英明雷用发光外观区分，带随机词缀，必掉好东西。

### 刷新

| 情况 | 规则 |
|---|---|
| 离开小地图返回大地图 | 整片刷新 |
| 原地 | 约 30 秒重生 |
| 精英 | 长 CD 或不刷新 |

刷子玩家清一圈落雁坡控制在三到五分钟。**刷一圈是一个舒服的循环单位**，不是一件苦差事。

### 密度

太密的话走两步打一架，探索被切碎；太疏的话刷子玩家满地图找怪。

原则：**主要路径上稀疏，支路和营地附近密集。** 玩家自然就会明白——想赶路走大路，想变强往岔路钻。用敌人密度引导探索，比放箭头好使得多。

### 可选杠杆：山寨警觉度

在大地图上打的巡逻队越多，进山寨后守卫配置越强。这样"要不要清野"就有了取舍，而不是无脑全清。

**不建议第一版就做**，但架构上留个口子。
