## 零、怎么读这份稿

- 每幕有 **① 目标 ② 在场 ③ 玩家做的事 ④ 拿到的信息 ⑤ 可跳过的深度 ⑥ 出口**；
- **「旁白草」「选项草」都只是候选**——挑一句就落，不挑就留白；
- **标「新提」的都是我的建议**，标「照设计」的是上游已定的；
- 幕与幕之间**不设强制过场**（沿用 18 §六 的三条纪律：不给任务箭头、不锁探索、主线信息至少两个来源）。

## 三、幕一～幕结（逐幕）

### 幕一·封着的水岸

| 项 | 内容 |
|---|---|
| **目标** | 让玩家发现第一章"看不进去"的那个地方现在进得去了，**并且知道是谁让他进去的** |
| **在场** | 无 NPC（只有景）；可选：老周（照设计，他第一章说过山里哪条路通哪） |
| **玩家做的** | 从封桩的缺口进去；看第一章那三处缝 |
| **拿到的信息** | ① 封桩拔了两根、泥是新的（**裴无咎先到**的第一个证据）② 断桥断口是新的、旧板被搬走了 ③ 水退半尺，露出一截对岸石阶 |
| **可跳过的深度** | 三处观察点**都可跳过**（不看也能进镇），但看了在幕三多一条能对厉青说的话 |
| **出口** | 走栈桥进镇（`bl_bridge` → `bl_town`） |

**旁白草**：

> 桩子拔了两根。拔的人没把桩带走——他不在乎你看出来。

### 幕二·水下的箱子

| 项 | 内容 |
|---|---|
| **目标** | **推翻一个说法**：十年来说的都是「银子沉了」 |
| **在场** | 可选：几个在浅滩捞东西的闲汉（**新提**：他们不认账，但认得"上个月有人来量过水深"） |
| **玩家做的** | 下水／拖网／问闲汉；三条路任一条都能通 |
| **拿到的信息** | 浅滩底下是**空的**——桩阵还在，箱子早没了。**银子没沉，是被搬走的**（照 20 §六「银子是被官府调包运走的」） |
| **可跳过的深度** | 硬判定（水性与体能）只影响"少湿一身衣服"；**不打判定也能知道** |
| **出口** | 回镇子（**这一趟回来会发生幕三**） |

**旁白草**：

> 桩阵是空的。十年前他们把箱子捆在这儿，捆得很规矩——然后从水路运走了，一根绳子都没留下。

> **新提的一个口子**：浅滩里卡着**半块船板**，上面一行墨迹被水冲得只剩两个字；
> 到第三章才拼得出是「白鹭」。**第二章只给半块**（"只埋不揭"的手法照 21 §二 对白清和那条的处理）。

### 幕三·谁在下游等着

**这一幕是第二章的主戏**，两个人在等：**厉青**（素材稿 §五）与**裴无咎**（素材稿 §六）。
顺序建议**先裴后厉**（照素材稿 §6.1：他先到）：先让玩家在一个"不想打你"的人身上松口气，
再撞上那个"随时能抓你、却不抓"的人。

| 项 | 内容 |
|---|---|
| **目标** | 让玩家第一次感觉**公门高于江湖**（照 20 §七 7.3「侠的困境」） |
| **在场** | 裴无咎（栈桥尽头）、厉青（旧票亭门槛）、可选：关渡 |
| **玩家做的** | 两场对话，**都不打仗**：① 跟裴无咎——他先问「关渡在册上第几个」；② 跟厉青——他要账册，你不用给也不用打 |
| **拿到的信息** | ① 裴无咎当年在「监守自盗」的具结上签过字（**已定**，素材稿 §6.4）② 厉青要的不是真相，是"这东西落在谁手里" ③ **名册第一页是关渡** |
| **可跳过的深度** | 裴无咎那条**可以不听**（绕开进镇），代价是幕结少一条证据；厉青**躲不开**（他坐在你要过的门里） |
| **出口** | 关渡的线索指向村坞（幕四） |

**关渡这段（新提，本稿最想要的一场）**：他在镇子边上（村坞口／旧票亭后），不是被绑着，是**自己坐着**。
他不解释为什么在册上，只说一句（照 20 §二 那句样张的精神）：

> 「你看看，写的是不是『盗』字。」

**他与裴无咎十年没说过话**——**新提的可选**：把两人放进同一个场景，这场戏不用一句解释，
**只要两个人都看见对方、谁都没开口**。要不要做这个「沉默的重逢」，是策划的判断
（做的话是这一章最贵也最值钱的一个镜头）。

### 幕四·名册上的活人

| 项 | 内容 |
|---|---|
| **目标** | 让第一章那个抽象的「名册」落到具体的人身上——**有人因为你开始付代价** |
| **在场** | 陈氏、老周，还有寨里几个人的家眷（照 20 §七 7.1）；追他们来的人 |
| **玩家做的** | 一场硬仗（护人／被围），以及一个**必须选边的小抉择** |
| **拿到的信息** | ① 名册不是"名单"，是**催命符** ② 追的人手里有官面上的凭据（**不是山贼**，与第一章「灭口的穿官靴」接上） |
| **可跳过的深度** | 村坞**可以不去**（那就变成"你没去"）——但按 18 §六 的纪律**主线不能断**：不去村坞，主线信息要能从"追兵打上门"那条路拿到 |
| **出口** | 回栈桥（幕结） |

**旁白草**：

> 你救了人。他们谢你的时候眼睛不敢看你——他们知道，你手里那几页纸，就是他们躲了十年的原因。

### 幕结·第二次两难

| 项 | 内容 |
|---|---|
| **目标** | 谢幕前再给一次「没有干净解」（接 20 §七 7.3 的"心态转变"） |
| **在场** | 厉青（一定要在），其余看前面怎么走 |
| **玩家做的** | 对「下半本怎么处置」做**第二次选择** |
| **拿到的信息** | 下半本的下落；以及**厉青不是最终的那个人**（把线接到第三章） |
| **可跳过的深度** | 无 |
| **出口** | `chapter_def.chapter_03`（占位） |

**三种收尾的方向（只给方向，不写死）**——注意：下面说的是**下半本**怎么处置，
与第一章那本**上半本**的去向是两件事（上半本的去向见 Q86：呈官／沉底＝已用掉，散页＝留原件）：

| 方向 | 一句话 | 代价 |
|---|---|---|
| 交出去 | 你把水下的东西捞上来，当着厉青的面交出去 | 他不再盯你，但名册上的人从此归他管 |
| 砸掉 | 你当着他的面把它毁掉 | 谁都拿不到，包括你——但你从此是"要办的人" |
| 留下来 | 你自己收着，谁也不给 | 三方都盯着你，第三章你走到哪儿都带着它 |

> **新提**：这一章**不要再给永久增益**（第一章那三样是"第一次尝到"的甜头）；
> 第二章的收尾该**只给代价与关系**——否则「两难」会退回成「选奖励」。
>
> **写词纪律（照 Q86）**：第二章的分档台词**只按 `flag_ledger_public`／`buried`／`scattered` 分**，
> **不写"你手里那本账"这类依赖物品在不在的句子**——呈官／沉底时账册已经离开背包，
> 散页才留着原件；按物品写死，会出现"身上没东西、台词却当它还在"的错。

## 六、与三档开局的挂点（哪些台词真的要分叉）

素材稿 §八 已定方向（呈官／沉底／散页各长一档差异）。**为了别让实现变成"三倍台词"**，
本稿建议**只在五处挂条件**，其余全章共用一套：

| # | 挂点 | 分叉什么 |
|---|---|---|
| 1 | 幕引那三句旁白 | 出发的心情（§二 已给） |
| 2 | 沈雁回在不在场 | 在 → 多两段对话；不在 → 由老周／孙掌柜的口信替代（**不新增 NPC**） |
| 3 | 厉青的**开场第一句** | 呈官＝「同路人」口吻；沉底＝盘问口吻；散页＝警告口吻 |
| 4 | 幕结那三种收尾的**可用选项** | 沉底那条**没有实物可交**——方向表里「交出去」要换成"带他去捞"（照 Q86：呈官／沉底账册已离开背包，散页留原件） |
| 5 | 名册上那些人**对你的态度** | 呈官 → 躲你；沉底 → 谢你；散页 → 谨慎试探 |

> 这五处之外**一律共用**——否则读者会觉得这是三个第二章，不是一章。
