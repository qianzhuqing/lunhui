## 和 32px 规格的关系

`07_地图资源需求.md` 定的瓦片是 **32×32**，这套包是 16×16，所以用脚本最近邻放大 2 倍：

```bat
python tools\mapgen\scale_atlas.py
```

输出 `assets/tilesets/_common/tiny_town_32.png`（384×352，12×11 格）。
五套主题 TileSet（`assets/tilesets/<主题>/<主题>_tileset.tres`）都引用这张放大图，
主题之间只差「收哪些瓦片、哪些挡路」。正式美术到位后替换那张 32px 图集即可，场景不用动。

## 为什么用 packed 版本

包里有两个图集：`tilemap.png` 每格之间留了 1px 间距，`tilemap_packed.png` 没有。
Godot 的 `TileSetAtlasSource` 只要 `texture_region_size = 16×16`、`separation = 0`
就能直接切 packed 版，少一层偏移计算，所以入库的是 packed 版（改名为 `tilemap_packed.png`）。

## 房屋配方

一栋 4 格宽的小屋 = 两行屋顶 + 一行墙：

```
行 y-2:  屋顶脊 (5,4) (5,4) (5,4) (5,4)
行 y-1:  屋顶   (5,5) (5,5) (5,5) (5,5)
行 y:    墙     (5,6) (4,7) (5,6) (7,7)
                 └墙    └窗    └墙    └门
```

青瓦版把 `5,4` / `5,5` 换成 `1,4` / `1,5`，墙换成木墙 `1,6` / 木窗 `0,7` / 木门 `1,7`。
